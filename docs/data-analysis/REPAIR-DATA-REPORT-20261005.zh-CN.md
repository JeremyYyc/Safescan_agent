## 6. 内容验收标准

1. 每个故障类型至少5张实际落盘、可解码、去重后有效图片；不能用重复尺寸版本凑数。
2. 现象图、维修步骤图、结果图分别标记；5张步骤图不是5个故障案例。
3. 图片关联原始指南、步骤ID、来源、作者、许可、时间及校验值，不脱离上下文。
4. 每类尽量覆盖多个指南或设备案例；没有达到的类别明确列缺口。
5. 正常状态、工具图、拆装图不能自动作为可见故障标签；内容判读和文件验证分开。
6. 不生成真实报修人、费用、工时、结单结果；模拟业务另行标记，不能与已采集房源拼成虚假事实。
