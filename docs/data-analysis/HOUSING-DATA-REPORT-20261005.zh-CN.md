## 4. 图片够不够

**用于基础房源展示不必补满全图库，但当前轻量采集的“前两张”策略不保证有效室内覆盖。**

既有抽看：Ann Street两张是阳台与客餐厨；A'Beckett两张主要为同一开放式客餐厨不同角度。两例都不能据此认定全屋已覆盖，本轮未把抽看扩大为全批视觉结论。

- 基础门槛：完整布局图+至少1张有效室内图；优先保留1至2张代表性照片。
- 精选空间分析样本：按客厅、厨房、卧室、卫浴的实际覆盖补图，不机械追求张数；多层图纸须完整。
- 广告、外观、泳池、大堂、同场景重复视角不替代室内关键空间。
- 不从未拍到的空间推断设施不存在，不从营销图片认定安全合规。

## 5. 与项目的对应

Property面向出租单元，包含地址、卧卫、车位、租金、状态、图片数组和单个floorplan_url。房型、多租期报价与多页图纸需经过暂存及映射，不能直接压平丢失来源。

后端原种子为4栋楼8套房源且无照片；员工端与租客端mock另有不同记录。真实资料接入必须统一ID与媒体访问方式，不能只替换一个mock文件就认为全链路一致。车位未知不能填0，需检查新增记录的数据库约束。

申请、租约、账单和维修不是公开挂牌事实；演示生成的业务记录要与采集事实隔离。现有资料没有对应的本地巡检视频和风险真值，不作为巡检准确率评测集。
