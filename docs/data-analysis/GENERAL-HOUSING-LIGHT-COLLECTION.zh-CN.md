# 轻量扩采规则

根据用户更新的要求，优先增加不同住宅和布局，不再完整下载每套图库。

## 每套保留

- 完整布局图：通常1张；若多个楼层分图，保留全部必要布局页，不机械截断为1张。
- 室内照片目标1至2张：采集阶段先取同一挂牌前2张图库候选图，不能自动声称是室内；外观、广告或公共设施图在后续核验时剔除或替换。
- 原始页面：完整保留，包括其余未下载的图片链接、报价、描述、公开的单元号或楼层信息。
- 已经保存的旧批次不删图、不覆盖；原始下载与清理结果分目录保存。

## 第三批

明确候选清单：`scripts/data_collection/general_batch_03_targets.json`，共20个新候选。
输出：`data/collection-pilot/general-batch03-light-20261001/`。
其中 Port Melbourne 的 302/2 Pier Street 返回410（已下架），保留失败记录；不计入成功采集房源。
其他19个页面保留原始HTML，结构化数据关联20张布局图、每套2张图库候选图，共58张计划下载图片。
实际成功与失败以 `summary.json` 和各目录 `outcomes.json` 为准。

质量标记包括历史已出租、示意照片、虚拟布置/AI声明；这些都是待复核信号，不能当作真实单元实拍通过。
独栋和联排住宅与普通公寓保留独立类型，不把它们都称为公寓。
图像文件相同采用SHA-256检测，房源按完整地址初步去重；不同单元并不自动等于不同布局，布局层面的相似去重留待视觉清理。

## 数量口径

候选数、页面成功数、已取得布局/图库的房源数、视觉通过数分开报告。
原始页面中的全部图片数不代表本次下载数。
当前扩采仍是选择性批次，不能据此确定全站可用总量。
用户操作授权不代表平台数据授权；原文件不去水印，未公开分发或用于训练，受限访问不绕过。
