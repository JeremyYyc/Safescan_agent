# 普通市场公寓样本核验（2026-10-01）

## 结论

本轮 5 套候选中，2 套纳入本地普通市场公寓研究样本，3 套待核验，不计入合格数量。
“社会公寓”在这里指非学生专属的普通市场住房，不指政策性社会住房。联排住宅独立分层，不混入公寓统计。
接受级别为“同一挂牌关联、人工视觉检查通过”，不是业主认证、现场测绘或图片真实性鉴定。

## 指标

| 指标 | 要求 | 是否硬门槛 |
| --- | --- | --- |
| 房源身份 | 普通住宅、具体地址，公寓保留公开单元号 | 是 |
| 完整布局图 | 能看清整套边界、入口、主要房间及连接；多层须包含所有住宅层 | 是 |
| 室内图片 | 至少一张有效室内照；广告、街景、外观不计入 | 是 |
| 图文关联 | 来自同一具体挂牌，对照门窗、厨房、卫浴和空间关系，无明显重大冲突 | 是 |
| 可追溯性 | 来源链接、原页面、采集时间、图片尺寸及 SHA-256 | 是 |
| 空间覆盖 | 优先覆盖起居、睡眠、厨房、卫生间；缺失项单列 | 优先 |
| 楼层与尺寸 | 有明确证据才填写；不从房号、庭院推楼层，不从图像估算米数 | 优先 |
| 报价 | 分离挂牌价、起价、历史价和租期；冲突不强行合并 | 独立验收 |
| 数据权利 | 保存权利未知状态；本地核验通过不代表获准公开分发或模型训练 | 独立门槛 |

不使用总分掩盖硬性缺失。布局完整不等于每个角落均有实拍，也不等于整栋建筑的疏散图。
