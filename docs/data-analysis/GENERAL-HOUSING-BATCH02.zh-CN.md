# 普通住宅扩采第二批

本批执行用户要求的“先采集，后验证与清理”。操作授权来自用户，不代表平台或图片权利人许可，也不清除已记录的网站条款风险。
遇到 robots 禁止、403 或限流停止，不绕过访问限制。用途仍为本地研究，未公开发布或导入训练集。

## 分层保留

输出目录：`data/collection-pilot/general-batch02-20261001/`。

- `pages/`：原始 HTML、robots、逐次成功/失败日志和校验值。
- `media/`：来源页面明确关联的原始图片字节，不去水印、不裁剪、不删除广告或重复图片。
- `raw_records.json`：从 HTML 结构化数据提取的原始字段，保留描述和报价。
- `media_targets.json`：所有计划采集的图片链接及其所属挂牌。
- `clean/provisional.json`：按完整地址初步去重后的记录，关联下载成功/失败图片，全部保持视觉待核验。
- `clean/audit.json`：逐条清理动作和问题标记。
- `clean/shared_media.json`：完全相同图片的 SHA-256 分组；只标注，不删除原文件，不等同于视觉近似去重。
- `summary.json`：实际下载数量和失败数量，以运行结果为准。
- `index.html`：原始页面、全部下载图片、初步清理结果的本地对照入口。
- `manifest.json`：结果文件的校验索引。

## 当前验收边界

“所有链接图片下载成功”不等于“完整布局图与室内图片匹配通过”。本批只完成采集与结构化初清；新增人工视觉验收数量暂为0。
后续逐图标记完整布局、室内、公共设施、外观、广告、示意与重复，输出独立的合格子集，原始目录始终保留。
