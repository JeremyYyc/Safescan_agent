## 2. 使用边界

| 使用场景 | 判断 | 主要条件或阻碍 |
| --- | --- | --- |
| 本地资料浏览、来源核验 | 可以继续 | 区分事实、候选、历史信息和未知值 |
| 房源展示演示 | 有条件 | 完成字段映射、选图、状态隔离和用途确认 |
| 真实可出租库存 | 不具备 | 学生缺具体单元，普通住宅含历史已租及状态冲突 |
| 维修知识库正式接入 | 尚未完成 | 图片失败、用途未确认、未做指南安全及适用性审核 |
| 真实维修工单 | 没有 | 指南不是报修、派单、处理、验收的业务记录 |
| 安全巡检评测 | 不具备 | 缺对应巡检视频、风险真值及空间覆盖标注 |

## 3. 本轮证据与核验方法

读取最新学生汇总、普通住宅三批的summary/provisional及既有审核记录、维修raw/clean/media_audit；核对本地文件，不用搜索结果推测已采集数量。

- 重新解码学生68张、普通住宅26+83+58张图片，共235张，失败0张；各目录内文件SHA-256均不重复。
- 本轮未对235张逐图重做视觉验收，也未完成跨来源的感知去重。能解码不等于图文匹配或内容合格。
- 维修137为原始API步骤中的图片引用次数，不是137张已下载图片，也不是137个案例。
- 历史试采、重复快照、replay和预览复制包不计入主批次数量；补充资产列于房源报告，不宣称上述主批次是仓库全部资产总数。

## 4. 优先问题

1. **记录粒度与系统不一致。** 房型、具体挂牌、报价、媒体需要分别保留，不能把房型直接当作真实Property。
2. **下载与验收混淆风险。** 普通住宅25条只完成初清；维修没有落盘图片。必须分别统计候选、成功下载、内容通过和用途获准。
3. **业务字段不足。** 后两批普通住宅25条尚未输出完整业务字段；学生报价币种及计价对象存在大面积缺失。
4. **历史状态及图像真实性边界。** 已租、示意、虚拟布置与样板图不能冒充当前真实房屋状态。
5. **使用权与技术可达性独立。** iFixit有条件许可、AHCD许可未确认；用户同意采集不替代来源授权。403后已停止。
6. **未形成可恢复的正式交付链。** 数据目录被Git忽略；代码提交不等于数据备份。需要独立备份原始字节、清理结果、索引及校验值。
