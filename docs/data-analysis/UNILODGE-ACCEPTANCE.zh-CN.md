## 报价变化的解释

同一组目标房型早期快照有 7 条报价，当前有 4 条：Standard 3→3、Queen 0→0、Terrace 2→1、两卧 0→0、四卧 2→0。Standard 两个保留方案的页面默认起租日期变化，不作为价格变化。

原始 HTML 中目标房型区块的报价条数与 JSON 一致，重新解析也与冻结输出一致。本轮无法判断缺失报价源于售罄、网站会话、展示策略还是其他原因；不报告市场降价、不拿旧价补空、不计算全平台均价。
