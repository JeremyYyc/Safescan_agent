# 安全与隐私文档

## 1. 威胁边界

保护对象包括账号、家庭成员信息、位置、视频/图片、报告、维修记录、知识库凭据和模型调用数据。主要威胁是越权读取、恶意文件、提示词注入、跨用户 RAG 泄露、密钥泄露和错误法规建议。

## 2. 认证与授权

继续使用 Bearer token；每个资源查询必须校验 owner 或显式共享关系。不要仅依赖前端隐藏按钮。MVP 只启用公共 Product/Safety KB；后续 Property KB 必须使用 tenant/owner filter 强制隔离，管理员操作单独审计。聊天上下文必须检查 chat 与 inspection 的归属，不能由客户端任意传入 inspection_id 切换上下文。

## 3. 文件安全

限制扩展名、MIME、大小、时长和分辨率；文件写入用户隔离对象 key；处理前做恶意文件扫描；媒体 URL 使用短期签名；下载接口不接受任意路径。

## 4. RAG 安全

外部文档和用户文档均视为不可信内容；检索内容不能覆盖 system policy。对来源做 allowlist、版本和人工发布；引用原文时限制长度并过滤敏感字段。若地区缺失、来源过期或召回分数低于阈值，系统只能降级为一般信息/无法确认，不生成合规结论。

## 5. 数据生命周期

MVP 默认保留周期：原始视频/中间帧 30 天，Evidence/结构化报告/PDF/聊天记录 180 天，安全审计日志 365 天，知识源版本在仍被引用期间保留。用户主动删除使用可恢复软删除：默认保留 30 天恢复窗口，窗口内资源不可被普通查询访问但可由所有者恢复；窗口结束后异步物理清理对象、关联记录和向量索引。用户可导出自己有权访问的数据，导出为 ZIP，使用限时下载链接。该策略已由项目所有者确认，作为独立项目的默认产品策略执行。

## 6. 安全验收

必须覆盖越权 IDOR、上传绕过、SQL 注入、SSE 鉴权、Prompt injection、跨用户检索、过期 token、删除后资源访问和密钥扫描。
