## 正文检查

对首轮四篇正文逐篇阅读，并结合保存的 HTML 结构检查提取：

1. 住房要求页保留七项基本要求和正文中的说明；法律引用链接保留。
2. 紧急维修页保留故障类型列表、烟感例外说明和租客通知职责。
3. 报修流程页保留紧急与非紧急两组步骤、限制条件及纠纷处理段落。
4. 房东职责页保留维修职责、烟感、非紧急维修及争议处理内容。

首轮发现分享按钮文案混入、只有子标题而丢失上级标题的问题。解析器 1.1 去除了社交分享区及相关页面推荐，加入 HTML 标题路径与正文超链接；修正后四篇均未检出 Facebook、LinkedIn 或 Email mail 等分享噪声。Fair Trading 帮助信息及法律引用刻意保留。

标题路径忠实反映源 HTML 的 h1-h4 层级，不是人工整理的业务分类；部分页面标题级别不规整，后续切片不要直接把标题路径当法律规则层级。本轮未做逐字校对、法律适用性验证或专家审核，记录仍为 `review_status=pending_review`。

## 来源与许可

四篇均保存原 URL、最终 URL、发布者、NSW 地区、英文语言、抓取时间、页面日期、HTTP 元数据、原始/正文哈希及正文链接。

检查了 [NSW Government 版权说明](https://www.nsw.gov.au/nsw-government/about-website/copyright)：一般内容采用 CC BY 4.0，但品牌标志、第三方材料和另行声明的内容有例外。采集器记录版权说明链接，单篇 `rights_status` 仍为 `pending_review`，不自动推定整份 HTML 的所有资源均可再发布。原文发布日期/更新日期来自网站 meta，不代表已核验的法律生效日期。
