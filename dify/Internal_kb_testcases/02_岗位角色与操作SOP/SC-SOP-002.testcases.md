# SC-SOP-002 测试用例（日班值班经理 Duty Manager 岗位手册）

> 被测文档：dify/Internal_kb/02_岗位角色与操作SOP/SC-SOP-002_日班值班经理-Duty-Manager-岗位手册.md

## 用例 1 —— 日班值班经理职责与和 Property Manager 的分工

- **case_id**: TC-SC-SOP-002-01
- **类型**: retrieval（信息定位）
- **难度**: 易
- **问题**（员工/住户的真实问法，中文，可含州名/业务线/编号术语）:
  > 站点里"日班值班经理"和"物业经理（Property Manager）"到底怎么分工？值班经理在当班里能拍板做哪些决定？
- **期望召回文档**: SC-SOP-002
- **期望锚点（章节）**: 「## 3. 岗位职责与授权范围」内的「3.2 岗位职责清单」「3.3 授权范围」「3.4 与 Property Manager 的分工」
- **回答必须覆盖/包含的要点**（2–4 条，短语即可，必须来自原文表述，禁止编造数字/条号/金额）:
  - 职责含晨会与人员到岗确认、系统检查与公共区域巡检、受理前台升级事件、监督供应商、处理费用与让步、完成交接班日志
  - 日班值班经理负责"当班现场"的即时处置与执行
  - Property Manager 负责"站点全局"的规划、制度、绩效、重大决议与长期事务
  - 可能升级为纠纷/诉讼/监管/媒体事件时应第一时间同步 Property Manager
- **不应出现/不应编造**: 不得把重大决策责任揽到值班经理名下；不得编造授权金额或时间数字；不得引用不存在文档编号。
- **验收方式**: 检索应命中 SC-SOP-002 的「## 3. 岗位职责与授权范围」锚点章节；回答可引用「SC-SOP-002 §3.2/§3.3/§3.4」并覆盖要点；不得引用不相关文档作为主依据。

## 用例 2 —— 现场事件处置（噪音、纠纷、违规）

- **case_id**: TC-SC-SOP-002-02
- **类型**: process_qa（流程步骤）
- **难度**: 中
- **问题**（员工/住户的真实问法，中文，可含州名/业务线/编号术语）:
  > 白天有住户投诉楼上太吵、听着还像有两住户在吵架，值班经理该怎么处理？可以当场认定谁对谁错吗？
- **期望召回文档**: SC-SOP-002
- **期望锚点（章节）**: 「## 5. 班中流程」内的「5.2 步骤二：现场事件处置（噪音、纠纷、违规、轻微事故）」
- **回答必须覆盖/包含的要点**（2–4 条，短语即可，必须来自原文表述，禁止编造数字/条号/金额）:
  - 先判断是否涉及人身安全、是否可能升级为冲突，再决定介入方式
  - 噪音按"先沟通、后记录、再升级"顺序处理
  - 纠纷遵循"先降温、再厘清、后定责"，把双方分开、避免当众争执
  - 涉及房屋/金额/人身/法律责任时不当场认定，转 Property Manager 或合规岗位
- **不应出现/不应编造**: 不得让值班经理当众当场认定责任或承诺费用补偿；不得编造具体罚款或天数。
- **验收方式**: 检索应命中 SC-SOP-002 的「5.2」锚点章节；回答可引用「SC-SOP-002 §5.2」并覆盖要点；不得引用不相关文档作为主依据。

## 用例 3 —— 报修工单分级与响应时限（跨文档）

- **case_id**: TC-SC-SOP-002-03
- **类型**: cross_doc（跨文档协作）
- **难度**: 中
- **问题**（员工/住户的真实问法，中文，可含州名/业务线/编号术语）:
  > 有住户报漏水量有点大，值班经理怎么定工单的分级和响应时限？这类"内部时限"是法定的吗？
- **期望召回文档**: SC-SOP-002（另需 SC-SOP-009）
- **期望锚点（章节）**: 「## 5. 班中流程」内的「5.5 步骤五：报修工单的分级与资源调度」
- **回答必须覆盖/包含的要点**（2–4 条，短语即可，必须来自原文表述，禁止编造数字/条号/金额）:
  - 对当日工单分级检查，确认紧急/优先/普通分配与响应时限合理
  - 紧急工单如漏水、燃气、门锁失效、影响安全的问题需及时处理
  - 供应商/维修人员到场前应确认是否需要住户在家、是否提前通知、是否影响其他楼层，尊重住户安静享有权
  - 分级与响应时限细则见 SC-SOP-009（属内部服务标准，非法规要求）
- **不应出现/不应编造**: 不得把工单内部分级时限表述为"法定期限"；不得编造具体小时/天数；跨文档引用仅限真实存在的 SC-SOP-009。
- **验收方式**: 检索应命中 SC-SOP-002 的「5.5」锚点章节并可召回 SC-SOP-009；回答可引用「SC-SOP-002 §5.5」及「SC-SOP-009」并覆盖要点；不得引用不相关文档作为主依据。
