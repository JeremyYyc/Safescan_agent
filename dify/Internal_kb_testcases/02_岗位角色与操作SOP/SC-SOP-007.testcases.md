# SC-SOP-007 测试用例（入住 Move-in/Check-in 操作 SOP）

## 用例 1 —— 学生线 U18 在读/监护入住核验

- **case_id**: TC-SC-SOP-007-01
- **类型**: process_qa（流程步骤）
- **难度**: 中
- **问题**（员工/住户的真实问法，中文，可含州名/业务线/编号术语）:
  > 学生公寓入住时，一位学生还没满 18 岁，我又要核验在读状态，又要确认监护人，具体要怎么做、什么情况下不能办？
- **期望召回文档**: SC-SOP-007
- **期望锚点（章节）**: 「## 4. 端到端编号步骤」内的 {4.6 步骤六：学生线附加——在读/录取与 U18 监护复核。}（亦可引用「## 5. 双业务线差异」的 5.2 学生线入住差异。）
- **回答必须覆盖/包含的要点**（2–4 条，短语即可，必须来自原文表述，禁止编造数字/条号/金额）:
  - 复核对住户的在读/录取状态与签证有效期，确认仍符合学生公寓居住资格
  - 对未满 18 岁的学生应复核监护人信息、监护人同意/知情情况，并确保监护人（或其授权人员）到场或按学校协议完成相应安排
  - 凡 U18 监护信息缺失、监护人未到场且无合理替代安排、或在读核验存疑的，员工不得擅自放行入住，应按 SAF 与学校协议处理
- **不应出现/不应编造**: 不得给出在读/签证具体有效期天数；不得编造监护到场时限；不得引用不存在的文档编号
- **验收方式**: 检索应命中 SC-SOP-007 的「## 4.」中 4.6（或「## 5.」中 5.2）锚点章节；回答可引用「SC-SOP-007 §4.6/§5.2」并覆盖要点；不得引用不相关文档作为主依据。

## 用例 2 —— 入住前检查清单与押金口径

- **case_id**: TC-SC-SOP-007-02
- **类型**: policy_qa（政策/规则要点）
- **难度**: 中
- **问题**（员工/住户的真实问法，中文，可含州名/业务线/编号术语）:
  > 住户到店办入住，我发现租约没签、押金也没到账，能不能先让他住进来？押金到底怎么托管？
- **期望召回文档**: SC-SOP-007
- **期望锚点（章节）**: 「## 3. 前置条件（入住前必须达成）」内的 {3.1 租约/协议签署核验。} 与 {3.2 押金/订金与费用到位。}
- **回答必须覆盖/包含的要点**（2–4 条，短语即可，必须来自原文表述，禁止编造数字/条号/金额）:
  - 入住前应核验租约/住宿协议已正式签署且日期相符；未签署、身份与协议主体不符或类型不匹配的不得安排入住（参考「## 7. 红线」7.1 不得在未达到前置条件时放行入住）
  - 应核验押金与订金已按州法与公司口径到位并开具/核实收据；未到位或金额不符的应暂停入住并转财务处理
  - 押金/订金金额上限、托管方式与存入系统（如 NSW Rental Bonds Online、QLD RTA、VIC RTBA、ACT ORS Bonds）按各州不同，以"按州现行法及官方指引执行"为口径
- **不应出现/不应编造**: 不得给出具体押金金额或托管天数；不得编造某州托管系统数字；不得虚构条号
- **验收方式**: 检索应命中 SC-SOP-007 的「## 3.」中 3.1/3.2（或「## 7.」中 7.1）锚点章节；回答可引用「SC-SOP-007 §3.1/§3.2」并覆盖要点；不得引用不相关文档作为主依据。

## 用例 3 —— 房况报告与押金结算、跨文档协作

- **case_id**: TC-SC-SOP-007-03
- **类型**: cross_doc（跨文档协作）
- **难度**: 中
- **问题**（员工/住户的真实问法，中文，可含州名/业务线/编号术语）:
  > 住户办入住，我要不要和他一起核对房间状况？这一步和后面的退租、押金结算怎么衔接？
- **期望召回文档**: SC-SOP-007（另需 SC-SOP-008）
- **期望锚点（章节）**: 「## 4. 端到端编号步骤」内的 {4.4 步骤四：房间核对与 Condition Report 签署。}
- **回答必须覆盖/包含的要点**（2–4 条，短语即可，必须来自原文表述，禁止编造数字/条号/金额）:
  - 住户与员工应共同进入房间，按房况报告（Condition Report）逐项核对，客观记录已有损坏、缺陷或损耗并确认抄表数
  - 双方应在房况报告上签名并注明日期；如可能附照片/视频并注明时间戳，作为日后退租对照与押金结算的依据
  - 房况报告应如实、完整、客观；凡与入住前状态有出入或住户有异议的，应先记录再按流程处理，必要时上报 Property Manager
  - 退租对照与押金处理衔接 SC-SOP-008《退租（Move-out/Check-out）操作 SOP》
- **不应出现/不应编造**: 不得给出具体抄表或押金抵扣数字；不得编造条号；不得引用不存在的文档编号
- **验收方式**: 检索应命中 SC-SOP-007 的「## 4.」中 4.4 及 SC-SOP-008；回答可引用「SC-SOP-007 §4.4 + SC-SOP-008」并覆盖要点；不得引用不相关文档作为主依据。
