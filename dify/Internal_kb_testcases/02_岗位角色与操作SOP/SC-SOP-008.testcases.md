# SC-SOP-008 测试用例（退租（Move-out / Check-out）操作 SOP）

> 被测文档：dify/Internal_kb/02_岗位角色与操作SOP/SC-SOP-008_退租（Move-out-Check-out）操作SOP.md

## 用例 1 —— 退租检查流程（信息定位）

- **case_id**: TC-SC-SOP-008-01
- **类型**: retrieval（信息定位）
- **难度**: 易
- **问题**（员工/住户的真实问法）:
  > 住户退租当天我们要检查什么、怎么留证据？
- **期望召回文档**: SC-SOP-008
- **期望锚点（章节）**: 「## 5. 端到端退租步骤」内的 5.3 退租检查（Check-out Inspection）
- **回答必须覆盖/包含的要点**:
  - 逐项核对墙面地面、门窗、家电、家私、卫浴、厨房、储物、家具完整性及是否有遗留物品
  - 检查全程以照片/视频取证并记录时间戳（证据标准见 SC-LGL-008）
  - 应依据入住 Condition Report 的既有记录逐项比对
  - 进入房间须先敲门、表明身份并征得住户同意
- **不应出现/不应编造**: 不得给出具体法定检查时限或周数；不得编造不在原文的检查项目或证据类型。
- **验收方式**: 检索应命中 SC-SOP-008 上述锚点章节；回答可引用「SC-SOP-008 §5.3」并覆盖要点；不得以其他文档作为主依据。

## 用例 2 —— 押金扣款与押金不得抵欠租（政策/规则要点）

- **case_id**: TC-SC-SOP-008-02
- **类型**: policy_qa（政策/规则要点）
- **难度**: 中
- **问题**（员工/住户的真实问法）:
  > 退租发现损坏，押金要怎么扣？租户还欠租金，能直接从押金里扣吗？
- **期望召回文档**: SC-SOP-008（另需 SC-LGL-007、SC-LGL-003、SC-LGL-008）
- **期望锚点（章节）**: 「## 5. 端到端退租步骤」内的 5.4 与 Condition Report 对照与扣款评估，及 5.7 押金处理交接（衔接 SC-LGL-003）
- **回答必须覆盖/包含的要点**:
  - 扣款仅适用于超出正常损耗、确有证据且属住户责任的项目
  - 严禁无据扣款、未核产即扣款、以"习惯性"为由对正常损耗扣款
  - 扣款需住户同意，或经法定程序（仲裁）确认后执行
  - 押金不得用于抵偿未决的欠租或未结清账务，除非符合州法并取得住户同意
- **不应出现/不应编造**: 不得给出押金扣款上限或法定具体金额；不得承诺"押金一定全额退还"；不得引用不存在的文档编号。
- **验收方式**: 检索应命中 SC-SOP-008 §5.4/§5.7；回答引用「SC-SOP-008」并联动 SC-LGL-007、SC-LGL-003；涉及扣款上限应说明以各州监管机构官方指引为准。

## 用例 3 —— 遗留物处理（边界/跨文档）

- **case_id**: TC-SC-SOP-008-03
- **类型**: boundary（边界/例外/不适用）
- **难度**: 中
- **问题**（员工/住户的真实问法）:
  > 住户退租后房间还留下东西没拿走，里面还有护照，能直接扔吗？
- **期望召回文档**: SC-SOP-008（另需 SC-LGL-010）
- **期望锚点（章节）**: 「## 5. 端到端退租步骤」内的 5.8 遗留物处理
- **回答必须覆盖/包含的要点**:
  - 登记造册（物品描述、数量、发现位置、时间）并在合理期限内告知住户限期认领
  - 逾期未认领按"内部留存期限 + 依法处置"流程处理
  - 贵重/证件类（如护照、电子产品、证书）单独封存并延长认领期
  - 遗留物若含可识别个人信息的，须遵循 SC-LGL-010 的隐私处理要求
- **不应出现/不应编造**: 不得说"直接丢弃或归员工所有"；不得给出跨州统一的法定留存天数；严禁私留、丢弃或挪用住户遗留物。
- **验收方式**: 检索应命中 SC-SOP-008 §5.8；回答引用「SC-SOP-008」并可联动 SC-LGL-010；对证件/医疗等敏感物品应上报并作合规保管，而非即时丢弃。
