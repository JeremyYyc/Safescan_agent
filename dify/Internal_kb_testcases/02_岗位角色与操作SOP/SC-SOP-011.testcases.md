# SC-SOP-011 测试用例（钥匙、门禁卡与进出控制 SOP）

> 被测文档：dify/Internal_kb/02_岗位角色与操作SOP/SC-SOP-011_钥匙、门禁卡与进出控制SOP.md

## 用例 1 —— 住户门卡丢失补办与收费

- **case_id**: TC-SC-SOP-011-01
- **类型**: process_qa（流程步骤）
- **难度**: 中
- **问题**（住户/员工问法）:
  > 我的门卡丢了，补办要收多少钱？流程怎么走？
- **期望召回文档**: SC-SOP-011
- **期望锚点（章节）**: 「## 7. 补卡与丢失流程（内部收费）」内的 7.1 丢失立即报告与两步走、7.3 补卡费（内部标准）与例外
- **回答必须覆盖/包含的要点**:
  - 发现丢失应立即报告；涉及高权限凭证丢失须第一时间升级 Duty Manager / Property Manager
  - 应先停用原卡权限（注销/挂失）再受理补卡，顺序不可颠倒
  - 补卡费为 Safescan 内部服务政策（非法规要求），标准住户门卡/公共区卡为 A$25/张
  - 减免须 Duty Manager 或以上审批；因门禁系统故障或卡正常失效导致换卡，不向住户收费
- **不应出现/不应编造**: 不得把补卡费表述为法定费用或给出无出处的金额；不得省略"先停用再补卡"。
- **验收方式**: 检索应命中 SC-SOP-011 的 §7 相关小节；回答可引用「SC-SOP-011 §7」并覆盖上述要点；不得以无关文档为主依据。

## 用例 2 —— 禁止尾随与转借门卡

- **case_id**: TC-SC-SOP-011-02
- **类型**: policy_qa（政策/规则要点）
- **难度**: 易
- **问题**（员工问法）:
  > 有人刷自己的卡刷卡时放朋友尾随一起进来，这种必须管吗？借用住户的门卡可以吗？
- **期望召回文档**: SC-SOP-011
- **期望锚点（章节）**: 「## 9. 使用规范：禁尾随、禁转借与门禁异常上报」内的 9.1 禁止尾随与转借、9.2 禁止私自复制与门禁异常上报
- **回答必须覆盖/包含的要点**:
  - 禁止尾随，应礼貌制止并提示走正常登记通道
  - 住户卡、员工卡、楼层卡与万能卡一律禁止转借、共享、出售或用于非授权用途
  - 员工不得私自复制、改装、克隆门禁卡或钥匙，不得绕过系统为他人"开权限"
  - 疑似被克隆/被破解应按安全事件上报，评估停卡、更换锁芯或重置权限
- **不应出现/不应编造**: 不得虚构处罚金额；不得引用不存在的文档编号。
- **验收方式**: 检索应命中 SC-SOP-011 的 §9 相关小节；回答引用「SC-SOP-011 §9」并覆盖要点。

## 用例 3 —— 学生退租当天的门卡回收与权限注销（跨文档）

- **case_id**: TC-SC-SOP-011-03
- **类型**: cross_doc（跨文档协作）
- **难度**: 中
- **问题**（员工问法）:
  > 学生退租当天，门卡要不要收回来？多长时间内要注销他的进出权限？
- **期望召回文档**: SC-SOP-011（另需 SC-SOP-008）
- **期望锚点（章节）**: 「## 11. 退租/离职卡回收与权限注销时限」内的 11.1 住户退租回收
- **回答必须覆盖/包含的要点**:
  - 按 SC-SOP-008 收回所有钥匙与门卡，核对卡类型
  - 权限注销须在回收后第一时间完成（内部标准：回收后 2 小时内完成系统注销）
  - 退租后原住户不得再持有可进入房间/楼宇的凭证；遗失按补卡/扣款流程处理
- **不应出现/不应编造**: 不得把"2 小时"表述为法定期限；不得引用不存在的文档编号。
- **验收方式**: 检索应命中 SC-SOP-011 的 §11 相关小节；回答引用「SC-SOP-011 §11」「SC-SOP-008」并覆盖要点。
