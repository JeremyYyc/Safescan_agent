# SC-EMP-001 测试用例（组织架构、治理与授权矩阵）

> 被测文档：dify/Internal_kb/01_员工政策与组织管理/SC-EMP-001_组织架构治理与授权矩阵.md

## 用例 1 —— 组织架构分层定位

- **case_id**: TC-SC-EMP-001-01
- **类型**: retrieval（信息定位）
- **难度**: 易
- **问题**（员工/住户的真实问法）:
  > 咱们 Safescan 的组织架构是几层？总部到站点是怎么管的？
- **期望召回文档**: SC-EMP-001
- **期望锚点（章节）**: 「## 3. 集团纵向管理架构（三层结构）」内的 3.1/3.2/3.4
- **回答必须覆盖/包含的要点**:
  - 采用"集团总部—区域—站点"三层结构
  - 站点日常指挥权归站点 Property Manager
  - 区域经理承担跨站点资源调配与总部-站点对齐，"一个出口"原则
- **不应出现/不应编造**: 不得虚构文档中未出现的层级或汇报关系
- **验收方式**: 检索应命中 SC-EMP-001 的「3. 集团纵向管理架构（三层结构）」；回答可引用「SC-EMP-001 §3」并覆盖以上要点；不得以不相关文档作主依据。

## 用例 2 —— 价格让步授权边界

- **case_id**: TC-SC-EMP-001-02
- **类型**: policy_qa（政策/规则要点）
- **难度**: 中
- **问题**（员工/住户的真实问法）:
  > 住户想让我给他减免一周租金，谁有权批？需要几级批准？
- **期望召回文档**: SC-EMP-001
- **期望锚点（章节）**: 「## 7. 授权矩阵（事项 × 角色 × 批准层级）」内的 7.1（授权矩阵表：个案价格让步行）/7.2
- **回答必须覆盖/包含的要点**:
  - ≤一周租金的个案价格让步由 Property Manager 批准，单次逐案记录
  - 超过一周租金须升级区域经理，并附出租率与竞争分析
  - 金额与权限为 Safescan 内部服务标准，并非法规要求
  - 授权底线：涉住户合同/押金/对外承诺等不可由现场员工自决
- **不应出现/不应编造**: 不得把内部金额标准当作法定金额，也不得编造审批数字或条号
- **验收方式**: 检索应命中 SC-EMP-001 的「7. 授权矩阵」；回答可引用「SC-EMP-001 §7」并覆盖以上要点；不得引用不相关文档作为主依据。

## 用例 3 —— 媒体采访升级（跨文档）

- **case_id**: TC-SC-EMP-001-03
- **类型**: cross_doc（边界/例外 + 跨文档协作）
- **难度**: 中
- **问题**（员工/住户的真实问法）:
  > 有媒体想来站点采访并拍照合影，我能不能直接答应？
- **期望召回文档**: SC-EMP-001（另需 SC-EMP-003）
- **期望锚点（章节）**: 「## 8. 决策升级路径与"四问"原则」内的 8.2（四问）/8.5；另见 SC-EMP-003「## 2. 核心价值观与对外代表形象」2.4
- **回答必须覆盖/包含的要点**:
  - 媒体采访/公开回应须升级站点头+总部公关，由统一口径发布
  - 属授权底线（不可分让）事项，现场员工不得自行决定
  - 四问原则：谁有权 / 是否核验 / 是否需升级 / 能否复盘
- **不应出现/不应编造**: 不得以个人身份代表公司对外表态；不得引用不存在的文档编号
- **验收方式**: 检索应命中 SC-EMP-001 的「8. 决策升级路径与"四问"原则」并同步命中 SC-EMP-003；回答可引用「SC-EMP-001 §8 / SC-EMP-003 §2」并覆盖要点。
