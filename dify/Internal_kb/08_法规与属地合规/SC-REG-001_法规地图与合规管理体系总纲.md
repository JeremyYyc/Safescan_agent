# 法规地图与合规管理体系总纲

> 本文档为虚构企业 Safescan 的内部模板，用于知识库演示；不构成法律意见，涉及法规处请以各州官方现行版本为准。本文档为合规操作指引，非法律意见。

本总纲是 Safescan 全部属地合规文档的顶层框架。它回答四件事：Safescan 在澳洲哪些法律之下运营；合规责任如何分工、如何记录；法规如何变化、我们如何跟上；员工遇到不确定时找谁。任何属地手册（SC-REG-002～005）与本总纲冲突时，以属地手册中"属地优先"的明确口径为准；属地手册未覆盖的，回退到本总纲。

## 1. 目的与适用范围

Safescan 同时运营 Safescan Living（长租公寓线，GR）与 Safescan Student（学生公寓线，PBSA）两类业务，并在 NSW、QLD、VIC、SA、WA、ACT、NT 多地设点。不同州对同一条事项（押金、预付租金、终止通知、涨租、维修、家暴终止）的规定并不相同，同一州内学生线与长租线还可能因协议类型不同而适用不同的规则。

本总纲的目的是：

1. 建立**一张跨州、跨业务线的法规地图**，让员工能一眼判断某事项"归哪个法、哪个监管机构管"。
2. 明确合规治理结构（Compliance Lead、各站点 Property Manager、HSQE Manager 的职责边界）与合规日历。
3. 定义法规更新监测与文档修订流程，确保知识库不因法规变化而过期。
4. 明确员工合规义务、违规上报路径，以及"属地优先"的统一处理原则。

**适用范围**：Safescan 全澳所有站点、全体员工、长期与第三方供应商/承包商交互时适用的合规要求。学生线（PBSA）与长租线（GR）如对同一事项要求不同，本总纲统一以"属地法规 + 协议条款"双重要求处理，具体差异在各属地手册与对应业务政策中展开。

## 2. 定义与缩略语

| 术语 | 英文/缩写 | 说明 |
|------|-----------|------|
| 长租线 | GR（Safescan Living） | 整栋自持（Built-to-Rent）高层公寓整租，主力 1–3 房全家具公寓，含灵活短租（≥3 个月）过渡产品 |
| 学生线 | PBSA（Safescan Student） | 整栋专建学生公寓，Studio / Twin-Share / Ensuite / Flat，租期以学期或学年为主，最短 12 周 |
| 住户 | Resident／Tenant | 长租线与学生线通用；学生线通常称 Resident，长租线亦可用 Tenant |
| 押金 | Bond / Security Deposit | 为担保履约向住户收取、由州托管机构持有或登记的可退还金额 |
| 订金 | Holding Deposit / Booking Deposit | 为保留房源先行支付，性质依州法与协议条款而定（可能转押金或冲抵首期租金） |
| 租约 | Residential Tenancy Agreement (RTA) | 长租线使用的州法标准住宅租赁协议 |
| 学生住宿协议 | Student Accommodation Agreement | 学生线使用的基础协议，通常并入物业所在州租赁法要求与 Safescan 学生住宿附加条款 |
| 合规负责人 | Compliance Lead | 全公司合规第一责任角色 |
| 风险登记 | Risk Register | 记录合规风险的登记册，含风险等级、责任人、缓解措施 |
| 复核周期 | Review Cycle | 本文档每 12 个月复核一次，法规变化时随时启动 |

> 术语解释须展开，"同一分点下解释不得只有一句"，上文各定义均含操作含义。例如"押金"的含义关键在于：它**不是公司收入**，而是受托持有的担保，必须按属地托管/登记要求处理，且收支必须与租金分开记账——这一点在任何站点都不得例外。

## 4. 合规治理与授权矩阵

### 4.1 合规治理角色

Safescan 的合规治理采用"公司层 + 站点层"两级结构，并明确"谁负责、谁批准、谁知情"：

| 角色 | 合规职责 |
|------|----------|
| Compliance Lead | 全公司合规第一责任人；维护法规地图与本文档；牵头法规监测、变更评估、文档修订；对重大合规风险向管理层升级 |
| 各站点 Property Manager（GR） | 属地运营合规（租赁、押金、进房权、终止、维修、condition report）；站点自查与记录；向上级升级属地风险 |
| 学生线 Property Manager + Community & Welfare Lead | 学生线属地合规与福祉合规（U18、家暴终止、学校协议、儿童安全相关）；升级路径同各站点 |
| HSQE Manager | 安全质量环境合规（WHS、消防、应急、供应商安全）；事故上报；与 Compliance Lead 联动 |
| 人力资源负责人 | 雇佣合规（NES、欺凌骚扰、伦理）；员工培训与违规处置对接 |
| 外部律师/顾问 | 按需为 Compliance Lead 提供法定解释、交叉复核属地手册、应对监管问询 |

### 4.2 授权与升级矩阵

| 事项类型 | 站点层可自主处理 | 需上报 Compliance Lead | 需上报管理层/外部律师 |
|----------|------------------|------------------------|------------------------|
| 常规押金收取、登记、退还 | 是（按属地流程） | 争议性抵扣、金额分歧 | 疑似违法操作、监管问询 |
| 终止通知、涨租、进房权 | 按属地手册执行并可发出 | 不确定法定情形/期限 | 涉及家暴、歧视、U18、重大争议 |
| WHS 事件、火灾 | 现场即时处置 | 应上报事件、填报记录 | 严重事故、监管介入、媒体关注 |
| 隐私、数据泄露 | 常规采集与使用 | 疑似泄露、新系统上线 | 重大泄露、OAIC 通知条件 |
| 法规解释、新要求 | 执行已知要求 | 对条文有疑问 | 需要法律意见 |

> 上表体现**属地优先、分级升级**：站点员工不应"凭记忆"承诺法定期限，也不应自行对外机构（警察、消防、福利机构、学校）的判断。凡属法定规则但员工不确定细节的，一律按"州现行指引为准"并升级到 Compliance Lead。

## 5. 合规日历与报告

### 5.1 合规日历

Safescan 建立周期性合规日历，防止"到期才想起来"。下表为公司层面统一节奏；站点级自查按各属地手册执行。

| 周期 | 动作 | 责任人 | 输出 |
|------|------|--------|------|
| 月度 | 站点自查（押金登记、condition report、进房权记录抽样） | 各站点 Property Manager | 自查表 |
| 每季度 | 押金/订金与账务对账；投诉与仲裁记录汇总 | 各站点 Property Manager + 财务 | 对账与汇总表 |
| 每 12 个月 | 本总纲及各属地手册复核；法规变化专项复查 | Compliance Lead | 复核记录、修订 |
| 每 12 个月 | WHS/消防一年度复审（含疏散演练、Warden 体系） | HSQE Manager | 复审记录 |
| 持续 | 法规监测（见第 6 节） | Compliance Lead | 变更评估 |

### 5.2 报告与留痕

- 所有自查、对账、复核、上报的记录均需**留痕**，记录保存以公司内部制度为准；属于法定记录的，保存期以属地法规为准（泛引，不写具体年限数字）。
- 合规日历的触发与完成情况由 Compliance Lead 在合规系统或共享台账中登记，作为审计依据。
- 任何明知或疑似违反法规的情况，须在发现后尽快（公司内部服务标准：**2 个工作日内**完成初次记录并上报 Compliance Lead，属内部标准而非法规要求）启动评估。

### 5.3 合规风险登记册（Risk Register）

Safescan 以风险登记册管理合规风险，记录风险、可能性、影响、缓解措施与责任人。下表为登记册字段与示例（风险等级数值为公司内部标准，非法定）：

| 字段 | 说明 |
|------|------|
| 风险编号 | 唯一编号（如 REG-RISK-001） |
| 风险描述 | 合规事项 + 潜在后果 |
| 主题 | 对应第 3 节地图主题 |
| 业务线 | GR / PBSA / 共用 |
| 州别 | 受影响州 |
| 可能性 | 低/中/高（内部标准） |
| 影响 | 低/中/高（内部标准） |
| 现值 | 低/中/高（内部标准） |
| 缓解措施 | 具体控制措施 |
| 责任人 | 角色 |
| 状态 | 开放/缓解中/已关闭 |

**示例行**（仅为演示，非真实项目）：REG-RISK-001｜NSW 押金未通过 RBO 托管｜主题：押金托管｜GR｜NSW｜中｜高｜高｜每月押金对账并核对 RBO 登记｜站点 Property Manager｜缓解中。

> 登记册由 Compliance Lead 维护，每季度评审一次（内部标准），作为内部审计与管理层复盘的输入；新出现的合规风险须即时登记并评估。

## 6. 法规更新监测流程

### 6.1 监测来源

Compliance Lead 负责建立一个多维度的监测来源清单，并定期检查（建议：**至少每季度**检查一次订阅有效性，属内部服务标准）：

1. **各州立法网站订阅**：通过各州 legislation 门户（如 https://www.legislation.nsw.gov.au、https://www.legislation.qld.gov.au、https://www.legislation.vic.gov.au 等，见基线 C 节）订阅所涉法规的修订通知。
2. **监管机构通告**：关注 NSW Fair Trading、QLD RTA、VIC Consumer Affairs Victoria、SA CBS、WA Consumer Protection、ACT ORS、TAS CBOS、NT Consumer Affairs 等官网的更新与行业指引。
3. **联邦**：OAIC（隐私/APPs）、Fair Work（雇佣）、Safe Work Australia（WHS 模范法）、legislation.gov.au（联邦法）的更新。
4. **行业通告与协会**：行业协会简讯、PBAS 运营商公开文件的版本变化（如学生公寓公开 Residence Rules、House Rules 的更新）可作为行业先导信号。
5. **标准机构**：AS 3745-2010、AS 1851 等标准目录信息（https://www.standards.org.au）。

### 6.2 变更评估与文档修订

一旦发现法规/指引/标准变化，按以下流程处置：

1. **记录并评估**：由 Compliance Lead 记录变化来源、生效日期、受影响的主题（对照第 3 节地图）。
2. **判定影响**：判断变化是否影响 Safescan 的（a）法定义务，（b）内部流程，（c）对外文件（协议、住户守则、表单），还是（d）仅需知悉。
3. **修订文档**：若影响 (a)–(c)，更新对应属地手册/政策，更新后**重新发布并注明版本与修订日期**；凡涉及法定数字且无法在基线 A/C 节找到出处的，一律改写为"按州现行指引为准"。
4. **培训与告知**：将重大变化通过培训或公告告知受影响员工（学生线、长租线分别告知）。
5. **更新基线**：若属新的已核实事实，回报知识库维护者更新 kb_build/02 法规基线 A 节；未核实的新细节不得写入任何正文。

> 任何作者不得在知识库中文档里引用"本基线文件之外"的条号、天数、周数、金额。这是 Safescan 知识库的铁律，违反即为文档缺陷，须在复核中修正。

## 7. 员工合规义务与培训

### 7.1 员工通用合规义务

1. **知悉并执行本总纲与所属属地手册**：员工在其职责范围内，应熟悉与岗位相关的属地合规要求（租赁、押金、进房权、终止、安全、隐私等）。
2. **不凭记忆承诺法定期限或金额**：凡属法定规则，仅在属地手册已明示时才可使用；否则一律"按州现行指引为准"，并引导住户查看官方口径。
3. **保护住户隐私**：住户个人信息（含年龄、国籍、残障、联系方式）仅用于合法目的，不得非法收集、使用、披露或跨境传输（Privacy Act 1988 与 APPs 适用；住户数据**不适用** employee records 豁免，见基线 A9）。
4. **平等对待**：不得基于种族、性别、残障、年龄等实施歧视，合理便利义务（如协助辅助犬使用者）须落实（见基线 A10）。
5. **报告安全隐患与合规风险**：发现安全隐患、疑似违规、数据泄露或不公平对待，按升级路径上报。

### 7.2 培训安排

- **入职培训**：新员工须接受与本岗位相关的合规基础培训（含本总纲、对应属地手册、隐私与反歧视、WHS 简介）。
- **周期性培训**：合规负责人每年组织一次法规更新与合规要点培训；WHS 与消防培训由 HSQE Manager 按年度安排（含 Warden 体系、疏散演练）。
- **专项培训**：学生线(Community & Welfare Lead)与长租线分别开展针对 U18、家暴终止、儿童安全、心理健康支持的专项培训，具体内容以行为规范与属地要求为准。
- 培训记录（签到、考核、完成情况）由人力资源与合规共同保存。

### 7.3 违规上报

- 员工发现本人或他人可能违反法规、公司政策，或收到住户/第三方投诉，应立即上报直属上级或 Compliance Lead。
- 公司鼓励主动上报且**不因善意举报而报复**；对恶意虚假举报仍可依员工政策处理。
- 上报后由 Compliance Lead 评估，必要时启动纠正与整改，并在合规台账留痕。

## 8. 双业务线 / 多州运营的合规统一框架（"属地优先"原则）

### 8.1 "属地优先"原则

Safescan 多州、双业务线运营，最易出错的是"拿一州规则套另一州"。因此统一采用**属地优先**三原则：

1. **属地法律优先于公司统一偏好**：凡法定事项，以物业所在州的现行法律为准；公司内部标准（如我们自己的服务响应时限）只在不与属地法规冲突的前提下适用。
2. **协议条款叠加属地法律**：学生线（PBSA）除州租赁法外还并入 Safescan 学生住宿附加条款；凡协议与州法不一致，以对住户权益更有利或属地法要求为准（对内提示，最终以官方与法务解释为准）。
3. **双线差异必须写明**：学生线与长租线对同一事项（预订单订金、押金、宠物、U18、家暴终止等）要求不同时，必须在流程中分别表述并说明原因（学生线受州租赁法/学校协议约束、楼宇分区管理等），不得混用。

### 8.2 一致性检查

- 同一事项在同一州内，学生线与长租线适用的法定口径应一致（因同受该州租赁法约束），差异主要来自**协议类型**与**附加条款**。
- 跨州对比类文档（如 SC-REG-005、SC-REG-006）中的"各州不同之处"应严格对照基线 A/C 节，凡未核实的数字一律留空或写"按州指引"并给官方链接。
- 凡涉及"下住学生、上住长租"的同楼分层楼宇，必须明确按**楼宇分区**分别执行对应协议与属地要求，不得跨区套用。

### 8.3 外部承包商与第三方合规

Safescan 的合规义务不因外包而消失。承包商（保洁、保安、维护、搬抬、消防维保等）、代理与学校合作方在站点作业时，Safescan 仍须承担现场管理、告知与监督责任：

1. **进场合规**：承包商进场前须确认其合规资质（安全、保险、许可证），并接受现场安全与合规告知（联动 SC-REG-009 与 TRN 相关文档）。
2. **现场监督**：站点 Property Manager / HSQE Manager 对承包商现场作业负有协调与监督责任；多雇主现场（Safescan 员工 + 承包方）须明确指挥与沟通渠道。
3. **数据处理**：代理、学校、征信机构等接收住户/学生个人信息时，若属向第三方披露，须符合 Privacy Act 1988 与 APPs（向第三方披露的合法基础判断见 SC-REG-008）。
4. **学校协议**：学生线与大学合作物业的运营受合作协议与学校要求约束，合规判断由 Compliance Lead 与学校共同确认。

## 10. 执行与监督

- 本总纲由 Compliance Lead 负责解释与监督执行；各站点 Property Manager 负责属地落地。
- 合规日历与自查记录由合规统一归集，作为内部审计与月度管理复盘的输入。
- 重大合规风险、监管问询、仲裁/投诉升级由 Compliance Lead 牵头，必要时协调外部律师。

## 11. 违规后果 / 升级路径

- 违反本总纲（未执行属地手册、擅自承诺法定期限/金额、泄露住户隐私、实施歧视、隐瞒安全隐患等）将按公司员工政策处理，情节严重者依政策处置。
- 员工面对"是否触法""时限是多少""该不该对外机构"等不确定时，**升级而非猜测**：直属上级 → 站点 Property Manager → Compliance Lead → 外部律师（按需）。
- 涉及住户人身安全、家暴、U18、自伤/他伤等，应第一时间联系对应机构（警方、福利机构、学校）并同步升级，不自行判断（见基线 B 节口径）。
