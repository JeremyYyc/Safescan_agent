# 日班值班经理（Duty Manager）岗位手册

> 本文档为虚构企业 Safescan 的内部岗位手册模板，用于知识库演示；描述的是本公司在长租公寓（Safescan Living，下称"长租线"）与学生公寓（Safescan Student，下称"学生线"）各站点日班值班经理（Duty Manager）的职责、授权、例行流程与处置权限。本文档不构成法律意见，涉及法律法规之处请以各州官方现行版本为准。

## 1. 目的与适用范围

**1.1 目的。** 本文档的目的，是规定 Safescan 各站点日班值班经理（Duty Manager）在日间班次内应当承担的职责与拥有的授权，明确其与 Property Manager（物业经理/站点总经理）的分工边界，规范其班前、班中、班后的例行动作，并对现场事件处置、服务供应商监督、费用与让步权限、住户特殊请求处理及交接日志作出统一要求。
日班值班经理是日间现场运营的"执行中枢"，承接前台升级的各类事项，并对站点公共区域的秩序、安全、服务与合规负当班责任，因此需要一份可培训、可审计、可交接的岗位手册作为依据。

**1.2 适用范围。** 本文档适用于公司在 NSW、QLD、VIC、SA、WA、ACT 六个州与领地运营的全部站点，包括长租线高层住宅塔楼（Residential Tower）与学生线学生公寓楼（Student Residence），以及"下住学生、上住长租"同楼分层物业。
凡本文档未单独说明差异的内容，视作对长租线、学生线均适用；当两线在某一事项上存在不同要求时（例如夜间静默时段、未成年人规则、噪音处置口径），本文档会以"5.x 学生线""5.x 长租线"分别说明，并提示日班值班经理在接班前确认本楼宇的分区边界。

**1.3 适用对象与责任矩阵。** 本文档的直接适用对象是各站点日班值班经理；其上位岗位为 Property Manager，其下位协同岗位包括前台接待（Reception / Concierge）、设施与维修协调员（Facilities Coordinator）、清洁领班（Housekeeping Team Leader）、保安（Security Officer / 外包保安）及学生线社区与福祉负责人（Community & Welfare Lead）。
当站点规模较小、无专职日班值班经理时，该职责可由 Property Manager 或指定资深前台代理，但代理者须同时满足本文档的授权与处置要求。

| 事项 | 行为主体责任 | 上报对象 | 升级时机 |
|---|---|---|---|
| 班次例行（晨会/系统检查/巡检/到岗确认） | 日班值班经理 | Property Manager | 发现重大异常时 |
| 现场事件处置（噪音/纠纷/违规/轻微事故） | 日班值班经理 | Property Manager；人身安全时加 CIMT | 事件升级、涉及法律时 |
| 服务供应商现场监督 | 日班值班经理 | Facilities Coordinator / Property Manager | 供应商违约或反复问题时 |
| 费用与让步审批 | 日班值班经理（限额内） | Property Manager | 超限额或涉法律金额争议 |
| 住户特殊请求 | 日班值班经理 | Property Manager | 承诺超授权或牵涉权利时 |
| 交接班日志 | 日班值班经理 | 接任班次（Duty/Night Manager） | 未办妥不得离岗 |

## 2. 定义与缩略语

**2.1 日班值班经理（Duty Manager）。** 指在日间营业/管理时段内，对站点现场运营、秩序、安全与服务承担当班职责的管理岗位人员；是前台升级事项的第一承接者，也是现场供应商与外包人员的日常监督者。

**2.2 现场事件（On-site Incident）。** 指在站点内发生的、需要管理介入的事件，包括但不限于噪音投诉、住户纠纷、违规行为、轻微事故、设备故障、突发健康或安全事件，以及与访客、外部人员相关的秩序问题。
现场事件按严重度分为一般事件与升级事件，升级事件须按本文档第 7 节处理。

**2.3 让步（Concession）。** 指公司对住户作出的费用减免、补偿或特别安排，属于金额与权利变动的决定。
让步分为"限额内可当场批准"与"须上报批准"两类，其界限见本文档第 5.6 节。

**2.4 服务供应商（Service Provider）。** 指为站点提供清洁、维修、保安、园林、设备维保等外包服务的第三方单位；其服务质量、合规与安全表现由日班值班经理在当班内监督，长期合同与 SLA 关系见 SC-TRN 相关文档。

**2.5 内部服务标准（Internal Service Standard）。** 指公司自行设定的响应时限、处置时限、让步幅度等政策数值，属 Safescan 自己的政策，并非任何州法的法定要求；凡本文档写明"内部服务标准""Safescan 政策规定"的数字，均属此类，并应与同库文档保持一致。

**2.6 应急组织与 CIMT。** 应急组织（Emergency Control Organisation）指按应急计划设立的岗位体系，通常包括 Chief Warden（总指挥）、Deputy Chief Warden（副总指挥）、Floor Warden（楼层指挥）与 First Aid Officer（急救员），按 AS 3745-2010 编制并定期复审。
Critical Incident Management Team（CIMT，危机事件管理组）指在公司层面统筹重大事件的处置、沟通与决策的团队，日班值班经理在现场处置重大事件时应向其同步信息并服从其总体协调。

**2.7 知情同意最小化。** 指在处理事件、调用住户信息或向第三方披露时，仅共享为处置与合规所必需的最低限度信息。
日班值班经理在涉及隐私敏感事件（如家暴、心理健康、医疗、U18）时应遵循这一原则，先联系机构、再按合规路径共享必要信息，避免过度披露。

## 3. 岗位职责与授权范围

**3.1 岗位定位。** 日班值班经理是站点白天的现场负责人与"第一升级承接人"，负责把前台汇聚的信息转化为可执行的动作，并在权限范围内作出处置决定。
其定位介于"具体执行"与"管理决策"之间：既要不脱离现场、亲自处理或协调具体事宜，又要保持管理视角，识别风险、安排资源并向 Property Manager 报告趋势，而非事必躬亲。

**3.2 岗位职责清单。** 日班值班经理应承担以下职责：执行并主持班前晨会与人员到岗确认；开展系统检查与公共区域巡检；受理并处置由前台升级的现场事件；监督清洁、维修、保安等服务供应商的现场表现；在授权限额内处理费用与让步事项；处理住户特殊请求并对超出权限者上报；维护公共区域秩序与安全；完成交接班日志并向下一个班次移交未办结事项。
所有职责均须以"安全、合规优先，服务其次"的顺序执行。

**3.3 授权范围。** 日班值班经理在授权限额内可作出的决定包括：对一般性环境、流程类问题进行现场响应与安排；对轻微违规或住户行为问题作出提醒、警告并记录；在授权限额内批准确认小额让步或费用调整；安排并调度现场资源（人员、供应商、设备）处理当班事务；在安全事件中按应急组织或 SAF 手册要求组织现场响应。
超出上述授权、或触及法律、合规、隐私、重大金额或住户权利的事项，必须上报 Property Manager 或相应上位岗位。

**3.4 与 Property Manager 的分工。** 日班值班经理负责"当班现场"的即时处置与执行，Property Manager 负责"站点全局"的规划、制度、绩效、重大决议与长期事务。
具体分工为：日班值班经理处理当班发生的、需要现场即时响应的事项并记录；Property Manager 负责站点整体运营指标、重大投资、合规整改、长期合同与人事决策。
当现场事件可能升级为纠纷、诉讼、监管或媒体事件时，日班值班经理应第一时间同步 Property Manager，而非自行承担决策后果。

**3.5 报告关系。** 日班值班经理向 Property Manager 报告，并在涉及员工管理、地点与设施事务时与相应岗位协同；在无 Property Manager 在岗或事件涉及公司层面时，直接向公司管理层或 Critical Incident Management Team（CIMT）升级。
凡在当班内发现可能违反法规、公司政策或涉及安全红线的事件，日班值班经理有义务如实、及时上报，不得因"问题不大"或"已自行解决"而隐瞒。

**3.6 应急组织角色。** 在发生应急事件时，日班值班经理通常担任或代行应急组织中的特定角色（如 Chief Warden、Deputy Chief Warden、Floor Warden 或 First Aid Officer，具体以站点应急计划与岗位任命为准），并按 AS 3745-2010 编制的应急计划履行相应职责。
日班值班经理应在班前确认自己当日担任的应急角色、对应应急岗位的责任区、疏散方案、集结区与应急联系人，并确保应急装备（如礼宾/值班包、疏散用具、急救包）在位可用。
凡发生火警、疏散、医疗或其他应急事件，日班值班经理应决定或协助启动应急组织，组织疏散、安抚住户、联系应急服务，并在事后配合完成事件记录与复盘。
应急事件的处理始终优先于一切常规运营，日班值班经理在应急期间应暂停常规服务、服从应急组织指挥，并在事件结束后如实记录，作为后续整改与培训的依据。

## 4. 班前准备与交接

**4.1 班前交接内容。** 日班值班经理应在接班前阅读夜班经理或上一班次留下的交接日志，重点关注：夜间发生的未办结事件、是否有待跟进的安全或设备异常、是否有住户或访客的夜间投诉、是否有计划当日到场的供应商或承包商、以及当天计划内的入住（Move-in）、退租（Move-out）、参观或开放参观安排。
对交接中标注为"高优先级"或"待回复"的事项，应排入自己当班的第一批处理清单，并在晨会上向相关岗位通报。

**4.2 晨会与人员到岗确认。** 日班值班经理应在日间班次开始后主持晨会，确认当日排班到岗情况，核对前台、清洁、保安及必要岗位人员是否到位，并向其传达当日重点事项（如入住/退租高峰、供应商到场、特殊住户关注、天气或安全提醒）。
晨会应简短、聚焦，做到"人人知道今天要做什么、遇到什么要报给谁"。
对人员缺席或临时调整，日班值班经理应即时安排并报告 Property Manager，确保责任岗位不存在真空。

**4.3 系统检查。** 日班值班经理应检查物业管理系统（PMS）、工单系统、门禁系统与 CCTV 等关键系统在当班开始时是否正常运行，核对是否存在异常告警、逾期未处理工单或门禁权限异常。
对系统故障或可能影响安全与合规的异常，应记录并按本文档第 7 节升级。
系统检查的完成以"关键系统可正常访问、无待处理高风险项"为标志，发现问题须在晨会后尽快处理或上报。

**4.4 公共区域巡检要点。** 日班值班经理应执行日间巡检，重点覆盖大堂、走廊、楼梯间、电梯、垃圾房、公共设施（健身、自习、社交、洗衣等）、消防通道与出入口、以及在建或维修区域。
巡检时应确认通道畅通、无堆积物、消防器材在位可用、照明与标识正常、公共区域清洁到位，并对发现的问题现场安排整改或创建工单。
巡检不只是一次性浏览，日班值班经理应关注"趋势"，例如同一区域的反复问题应是管理改进的信号，而非单纯的重复报修。
为便于执行，日间巡检可按"安全、卫生、设备、秩序"四类逐项检查。
安全类包括消防器材在位且压力正常、疏散通道与安全出口畅通、应急照明与疏散标识完好、无明火与易燃物违规堆放。
卫生类包括公共区整洁、垃圾房无溢出、异味处置及时、入口无杂物堆积。
设备类包括门禁、电梯、照明、通风、监控与公共设施运行正常，发现故障即转工单处理。
秩序类包括公共设施使用规范、访客行为合规、无肢体冲突或可疑人员滞留，发现问题即时处置或记录上报。

**4.5 完成标志。** 班前准备的完成标志是：日班值班经理已完成交接核对、主持晨会并确认人员到岗、完成系统检查、完成公共区域巡检，并将当日重点事项与异常情况在晨会或日志中记录与传达。
未完成关键班前检查（尤其系统与安全相关项）时，日班值班经理不得进入正常运营状态，应边处理边如实上报。

## 5. 班中流程（端到端编号步骤）

**5.1 步骤一：承接前台升级事项。** 日班值班经理应作为前台升级事项的第一承接者。
接到前台转交的事项时，应记录事件要点、判断性质与严重度、确定处置路径并安排责任人。
对可在当班内处理的一般事项，应给出明确的处理时限与结果；对需要跨岗位、跨部门或涉及权利的事项，应按本文档第 7 节升级。
承接事项后，日班值班经理还要把进展及时反馈给前台，以便前台向住户/访客作出一致答复，避免"住户多头询问却无人负责"。

**5.2 步骤二：现场事件处置（噪音、纠纷、违规、轻微事故）。** 日班值班经理在处理现场事件时，应先判断事件是否涉及人身安全、是否可能升级为冲突，再决定介入方式。
对于噪音投诉，应核实投诉方与被投诉方、了解静默时段与站点守则，以"先沟通、后记录、再升级"的顺序处理；对于住户纠纷或违规行为，应保持中立、依法依规、避免激化，并在必要时请保安或其他岗位协助；对于轻微事故，应优先保障人员安全与现场秩序，并按规定完成事件记录。
凡事件涉及人身安全、可能升级为暴力、或可能涉及违法或法律责任的，日班值班经理应立即呼叫相应的应急服务与上位岗位，不得自行判断或压制。
噪音类事件的具体处理分步为：第一步，向投诉方了解噪音来源、持续时间与影响情况并如实记录；第二步，向被投诉方或涉事区域核实情况，保持中立、不发难、不预设立场；第三步，视程度作出提醒、口头警告或书面记录，并说明所属站点守则的依据；第四步，若噪音仍持续或升级，按守则作出正式警告或书面通知，并同步相应流程，必要时请保安介入，学生线还应结合学生线社区规则与 Community & Welfare Lead 协同。
纠纷类事件的处理原则是"先降温、再厘清、后定责"：日班值班经理应先把当事双方分开、避免当众争执，再分别听取情况、如实记录，最后依据站点守则与公司口径给出处理意见；凡事件涉及房屋、金额、人身或法律责任的，应避免当场认定事实或承诺结果，转由 Property Manager 或合规岗位处理。
违规类事件应区分"轻微提醒"与"正式违规"：对可即时纠正且无严重后果的行为（如公共区遗留物、短暂噪音、轻微卫生问题），以提醒与记录为主；对反复违规、骚扰、威胁、破坏或涉及安全的行为，应作正式记录、按守则发出适格通知并向上位岗位升级，必要时按州法规定的违规通知机制办理，具体以公司相关文档与州现行法为准。
轻微事故的处理应遵循"救人、报备、记录"：先确保现场人员安全并满足急救需求，再向上位岗位报备并联系相关部门，最后完整记录事故经过、涉及人、损失、处理与后续跟进；不得因轻微而省略记录，因为轻微事故也可能是重大风险的先行征兆，完整记录有助于后续分析。

**5.3 步骤三：服务供应商现场管理监督。** 日班值班经理应监督当日到场的清洁、维修、保安等服务供应商工作，确认其是否按约定时间段、范围与质量标准执行，是否佩戴工牌、遵守现场安全规定与进出登记要求。
对供应商质量问题，应即时指出并要求整改，必要时记录并组织返工；对反复违约或涉及安全问题的供应商，应上报 Facilities Coordinator 与 Property Manager，由其对合同与 SLA 关系作出评价或处理。
监督的目的是保证服务质量与现场风险可控，而非替供应商替岗执行。

**5.4 步骤四：门禁、钥匙与进出控制的当班督导。** 日班值班经理应督导前台与保安在门禁、钥匙、访客、尾随处理上的执行情况，确保钥匙与门卡的发放、回收、补卡与权限注销符合 SC-SOP-011。
发现进出控制漏洞、疑似尾随、门禁系统异常或万能卡使用不规范时，应即时纠正并记录，必要时上报。
作为授权岗位，日班值班经理应对万能卡与楼层卡的使用负监督责任，避免因管控不严造成安全隐患。

**5.5 步骤五：报修工单的分级与资源调度。** 日班值班经理应对当日工单进行分级检查，确认紧急、优先、普通工单的分配与响应时限是否合理，确保紧急工单（如漏水、燃气、门锁失效、影响安全的问题）得到及时处理。
在供应商或维修人员到场前，应确认现场条件（如是否需要住户在家、是否需提前通知、是否影响其他楼层），并与前台、住户协调时间，尊重住户的安静享有权。
工单分级与响应时限的细则见 SC-SOP-009（内部服务标准：紧急≤2小时响应、优先当日处理、普通3个工作日内）。

**5.6 步骤六：费用与让步权限，住户特殊请求处理。** 日班值班经理在授权限额内可对下述事项作出确认：小额让步、补卡费或小额费用调整、对延迟服务或轻微质量问题的补偿；超过授权限额、或涉及租金、bond、罚款、法定期限、转租、退款、续约等法律与权利事项的，必须上报 Property Manager。
对住户特殊请求（如房间调整、家具/设备临时安排、健康或无障碍便利、学生线学业相关关照），日班值班经理应评估其合理性、可行性、是否涉及他人权益与权限边界，并在授权内处理、超出时上报。
凡涉及金额或权利的让步，日班值班经理均应记录依据、金额、审批人与理由，做到可追溯，严禁口头承诺无记录。
为便于执行，让步与费用审批划分为三层：第一层为"日班值班经理授权内"，指小额、一次性、不涉法律与权利的费用调整或补偿，可当场确认并记录；第二层为"Property Manager 授权内"，指中等金额、需要多个条件判断或可能影响住户关系的决定，需由 Property Manager 确认；第三层为"公司层面/合规审批"，指涉及租金、bond、法定通知、罚款争议、退款、转租等法律与权利事项，必须上报并取得授权，日班值班经理不得单独处理。
日班值班经理在处理让步与特殊请求时，还应评估"是否会对其他住户产生不公平、是否会被误解为惯例、是否会留下先例"，避免因单次让步形成后续难以管理的口径；凡可能形成惯例的决定，应报 Property Manager 统一口径，而非自行固化。
对于无障碍、健康相关或辅助犬等涉及合理便利（reasonable accommodation）的请求，日班值班经理应予以认真评估并上报，不得以"麻烦""不方便"为由拒绝；涉及《Disability Discrimination Act 1992 (Cth)》与州反歧视法时，应遵循公司反歧视与合规指引（见 SC-EMP 与 SC-REG 相关文档）。

**5.7 步骤七：投诉中高阶处置与记录。** 日班值班经理应接办由前台升级的投诉，尤其涉及人身安全、歧视、骚扰、隐私、法律权利或投诉对象为物业员工本身的投诉。
处理时应先完整记录事实，判断是否需要联系 Compliance Lead、CIMT 或外部机构，并在期限内回复住户。
凡事件可能引发监管、诉讼或媒体关注时，应立即上报 Property Manager 与公司层面。
投诉的处理应做到"有记录、有回应、有整改、有回访"，而非简单安抚后存档。

**5.8 步骤八：公共区域与秩序维护。** 日班值班经理应持续关注公共区域秩序，包括公共设施使用、访客行为、吸烟/饮酒/噪音等守则条款的遵守情况，并对违规行为按站点守则采取提醒、警告或升级措施。
对涉及学生线的公共区域行为（如社交空间、自习区、公共厨房），日班值班经理应结合学生线社区规则与 Community & Welfare Lead 协同处理。
其目标不是"执法"，而是维持一个安全、有序、相互尊重的居住环境。

**5.9 步骤九：数据保护与合规边界。** 日班值班经理在处置事件、调阅系统、向供应商或第三方沟通时，应遵守《Privacy Act 1988 (Cth)》与 Australian Privacy Principles，只访问与岗位职责相关的个人信息，不向住户之外的第三方披露敏感信息。
在处置涉及住户隐私的事件（如家暴、心理健康、医疗、U18）时，应遵循州法与相关机构协议，第一时间联系机构而非自行判断，并把信息共享严格限制在合规与安全所需的范围。

**5.10 步骤十：记录与系统更新。** 日班值班经理应将当班处理的事件、决定、让步、工单、供应商问题与投诉进展及时、准确录入对应系统或记录，注明时间、操作者、事实、依据、处置与结果。
记录应客观、完整、可追溯，不虚构、不推测、不补注他人未经确认的信息。
事件与投诉记录应按本文档第 9 节长期保存，以便后续调查、整改与法律举证。

**5.11 完成标志。** 日班班中各项流程的完成标志是：当日升级事项均已被承接并给出处理路径；现场事件均已被处置或上报并有记录；供应商当班工作已接受监督并确认基本达标；门禁、钥匙、工单、让步与投诉均在权限内处理或上报；所有事项已录入系统与日志。
凡尚未处理完毕的事项，必须移交交接日志并明确目标岗位与时限，不得留白。

**5.12 双业务线处理差异。** 日班值班经理在处理当班事项时，应区分长租线与学生线的不同要求，避免用同一口径处理所有事项。
学生线受州租赁法与学校/住宿协议的双重要求约束，且多数住户为在读学生，部分可能为未成年人，因此日班值班经理在学生线处理噪音、访客、违规与特殊请求时，应更关注社区规则、在校身份、未成人与学业相关因素，并与 Community & Welfare Lead 协同。
长租线住户多为成年租户，其事项更多涉及租赁关系、租约条款与物业责任，日班值班经理应更侧重租赁法规、房屋状况与争议处理的合规口径。
在学生线，若住户为未成年人（U18），日班值班经理在处置涉及该住户的事项时应遵循未成年人保护与监护相关流程，必要时联系其监护人或学校，且在共享信息时严格控制在合规与安全所需范围内；长租线通常不涉及此类安排，但仍应遵守反歧视与隐私规定。
凡两线均适用的事项，日班值班经理应按照统一的物业标准处理，并在记录中注明适用的业务线，以便后续检索与合规归因。
双业务线差异的另一个重要方面是"楼宇分区"：在同楼分层物业中，"下住学生、上住长租"或不同楼层用途不同，日班值班经理在处置噪音、访客、吸烟或灭火、疏散等事项时，应按楼宇分区边界执行对应规则，并在交接与记录中明确分区，避免因分区不清造成处置依据混乱。

## 6. 班后交接与封存

**6.1 交班内容。** 日班值班经理在下班前应整理当班完成与未完成事项，写入交接班日志（Shift Log），内容至少包括：当班处理的现场事件与投诉及处置结果；创建或接收的工单与状态；供应商到场与服务情况；门禁、钥匙、进出控制相关操作；做出的费用或让步决定及依据；未办结事项与建议处理时限；对下一班次（含夜班）的安全与合规提醒。
交接日志应让"从未接手该班次的同事也能接手"，因此要写清过程、依据与责任归属。

**6.2 交接班日志（Shift Log）模板字段。** 交接班日志建议包含以下字段：班次与日期/时间；当班值班经理姓名；接班时异常与未办结事项；本班次处理事项摘要（每项含分类、发生时间、涉及人、处置与结果、责任人）；工单状态（新增/进行中/待跟进/已完成）；供应商服务情况；让步与费用记录（金额、审批人、理由）；关键系统与设备状态；对下一班次的安全/合规/服务提醒；签名与时间。
该模板字段用于保证交接的完整与可追溯，也便于审计与绩效评估。

**6.3 现场与信息封存。** 日班值班经理在下班前应确认公共区域基本有序、无高风险遗留问题、系统已正常记录、敏感信息页面已退出登录、物资与钥匙已归位。
对需要在晚间继续处理的紧急事项，应当面或通话与 Night Manager 交接清楚，确认其已掌握现场情况与应急联系人。
完成标志：交接日志已签署、未办结事项已移交并确认接收、关键异常已直达下一班次。

## 7. 异常与升级分支

**7.1 明确的升级触发条件。** 当出现下列任一情形时，日班值班经理应立即升级，不得等本班次结束：涉及人身安全、火灾、紧急医疗、威胁、暴力或主动攻击者；疑似自我伤害、心理健康危机或涉及未成年人（U18）；投诉指向物业员工、或涉及歧视、骚扰、隐私、法律权利；涉及金额或权利争议（租金、bond、罚款、误报出警费、转租、退款、续约）且超出授权；门禁、钥匙、CCTV 或进出控制出现可能影响安全的异常；疑似数据泄露或越权访问；供应商严重违约或存在重大安全问题；事件可能引发监管、诉讼或媒体关注。

**7.2 升级通道与优先级。** 升级的一般路径为：日班值班经理 → Property Manager → Compliance Lead / Critical Incident Management Team（CIMT）→ 公司管理层；在涉及人身安全时，应同时呼叫相应应急服务（000/急救/警方），并同步 Night Manager 与 CIMT。
优先级安排为"生命与安全 > 合规与隐私 > 金额与权利 > 一般服务"。
升级时，日班值班经理应提供时间、人、地点、事件、已采取措施、住户期望与风险判断，避免只给模糊描述。
判断是否需要升级时，日班值班经理可参考三个问题：一是事件是否触碰到安全、合规、隐私、金额或权利的红线，二是事件是否超出自己的授权或能力范围，三是事件是否可能升级为纠纷、监管、诉讼或媒体关注。
当三个问题中任一个答案为"是"时，就应立即升级，而不是先尝试自行解决。
升级沟通应做到"及时、如实、完整"。
及时指不得拖延到班末或次日才报；如实指只陈述事实与已确认信息，不夸大也不缩小；完整指把关键上下文、涉及人、已采取措施与风险判断一并传递，减少上位岗位因信息不全而误判的风险。

**7.3 升级后的角色保持。** 一旦事件被上位岗位或 CIMT 接办，日班值班经理应保留现场信息、协助现场秩序与证人记录，直至上位岗位明确接手。
日班值班经理可以停止对事件结论作承诺，但须如实补充信息、避免对外臆测事件结果，并在交接时明确记录当前负责人与下一步动作，防止出现"两台都以为对方在跟进"的真空。

## 8. 红线（绝对不能做的事）

**8.1 安全与生命红线。** 日班值班经理绝不允许在未确认安全的情况下压制、推迟或隐藏任何火警、医疗、威胁或疑似犯罪事件；绝不允许在应急组织确认前擅自宣布疏散结束或消防误报；绝不允许因"怕麻烦""怕影响口碑"而掩盖现场事故或有违安全红线的问题。

**8.2 信息与隐私红线。** 日班值班经理绝不允许向未经授权的人员泄露住户、访客、承包商或员工个人信息；绝不允许在公开场合或非必要人员在场时讨论住户隐私；绝不允许越权调阅或导出数据。
特别是在涉及家暴、心理健康、医疗、U18 等敏感事件时，日班值班经理应严格限制信息共享范围，遵循"先联系机构、再共享最小必要信息"的原则。

**8.3 金额与权利红线。** 日班值班经理绝不允许在授权限额之外作出涉及金额或住户权利的承诺，包括免租、减免 bond/罚款、承诺法定期限或续约/退款/转租结论、作出无记录的口头补偿。
凡超限额或涉及法律事项，一律上报 Property Manager，并以书面或系统记录为准，严禁"先答应、再补申请"。

**8.4 现场处置红线。** 日班值班经理绝不允许在肢体冲突、疑似暴力或潜在犯罪场景中独自冒险介入而不呼叫支援；绝不允许在事件可能升级为法律纠纷时自行代表公司作出责任认定或让步承诺；绝不允许对供应商或住户的明显危险行为（如违规动火、堵塞消防通道、尾随进入）视而不见而不处理。
在处置现场时，日班值班经理还应避免"单人独自处置高风险场景"：凡涉及人身安全或潜在冲突，应确保有同伴支援或保安在场，自身不以人身介入为代价换取处置效率。
日班值班经理不应在情绪化或信息不全的情况下对住户作出结论性评价或威胁性表述，也不应在现场威胁住户"会被赶走"或作出守则之外的处理承诺，以免引发纠纷或法律后果。

**8.5 行为操守红线。** 日班值班经理绝不允许在岗位上饮酒或受毒品影响、与住户发生不恰当争执、擅自隐瞒错误、事后补造记录或推卸责任。
凡发生或发现自己造成的错误，应立即如实上报并记录，而非掩盖；日班值班经理作为管理岗位，其隐瞒行为对组织信任与合规的破坏比前台更严重。

## 9. 记录保存

**9.1 需保存的记录。** 日班值班经理应保存的记录包括：交接班日志（Shift Log）、现场事件记录、投诉处理记录、供应商服务情况记录、工单相关记录、让步与费用审批记录、巡检记录、系统检查记录，以及关键事件（安全、合规、隐私、事件升级）的完整记录。
记录应客观、完整、可追溯，并注明操作者与时间。

**9.2 保存方式与期限。** 日常记录优先采用系统电子记录，纸质记录按站点要求归档；凡涉及事件、投诉、隐私、纠纷、让步或合规的记录，应按公司记录保存政策与相关法规要求保留，且不因人员轮岗或离职而丢失。
涉及诉讼、监管或可能长期引用的记录，应按需要延长保存期限，并到期归档或按隐私规范删除非必要信息。

**9.3 数据保护。** 记录的访问与存储须符合本文档第 5.9 节的数据保护边界，限制为岗位职责所需的最小范围，并定期检查是否存在越权访问或不当留存。
日班值班经理不得以任何理由将记录用于与岗位职责无关的目的，也不得在离职或调岗时带走或复制住户数据。

## 11. 文档控制

**11.1 版本与维护责任。** 本文档由物业运营部（Property Manager）维持，合规负责人（Compliance Lead）复核；在法规变更、站点流程调整、组织架构变化或发生重大事件后应即时复审。
