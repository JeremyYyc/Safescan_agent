# 钥匙、门禁卡与进出控制 SOP

> 本文档规定 Safescan 全澳各站点钥匙、门禁卡与进出控制的全流程操作，涵盖凭证类型与分级权限、发放登记、补卡与丢失、锁门开锁服务、禁尾随与禁转借、门禁异常上报、CCTV 联动，以及退租/离职后的回收与权限注销。适用对象为长租线（Safescan Living，GR）与学生公寓线（Safescan Student，PBSA）全部站点，凡属同楼混合业态一律"按楼宇分区执行"。文中补卡费、开锁费等金额均为 Safescan 内部服务标准，非法规要求；涉及进房权、通知义务、监控隐私与各州禁止收费清单等事项，以州现行法及官方指引为准。本文档为虚构企业 Safescan 的内部模板，用于知识库演示；不构成法律意见，涉及法规处请以各州官方现行版本为准。

## 1. 目的、适用范围与合规前提

1.1 **目的。** 本 SOP 建立 Safescan 统一的钥匙、门禁卡与进出控制流程，确保楼宇、分区、房间与运营区域安全，防止未经授权进入、尾随、转借与冒用，并在凭证丢失、系统异常或涉安全事件时提供以人身安全为第一优先的处置路径。进出控制是物业安全的物理底线，其管理一旦出现漏洞，往往会成为入侵、盗窃与纠纷的根源。

1.2 **适用范围与业务线差异。** 本 SOP 适用于所有自营站点（含同楼分层物业的分区执行），既包括住户入住（SC-SOP-007）与退租（SC-SOP-008）时的凭证交接，也包括员工入职（SC-EMP-007）、离职（SC-EMP-009）与承包商、访客的进出凭证管理。长租线住户通常持房间与楼宇入口卡；学生线住户卡还常涵盖健身房、公共厨房、自习区等公共区权限，且开学期集中发卡量大，并因涉及 U18 学生与学校协作而合规敏感度更高。两线均须遵守"一人一卡、不得转借、不得尾随"的共同底线，差异主要体现在权限范围与接待流程上。

1.3 **合规前提与衔接。** 进出控制涉及可识别个人的录像与门禁刷卡记录的收集，受《Privacy Act 1988 (Cth)》及 APPs 约束，住户数据不适用"employee records"豁免（见 SC-REG-008）。凡进住户房间执行开门、检修或检查，须遵守州租赁法对进房权与通知的要求，确保不打扰住户的安静享有权，以州现行法及官方指引为准；应急疏散时，进出控制须服从 AS 3745-2010 体系下的应急管理安排（见 SC-SAF-001）。本 SOP 与多个文档闭环衔接：入住按 SC-SOP-007、退租按 SC-SOP-008、离职按 SC-EMP-009、门禁/CCTV 安保联动见 SC-SAF-013，且进出控制状态须作为交接班"物理区"内容确认（见 SC-EMP-001）。

## 2. 定义与缩略语

2.1 **凭证类型。** 门禁卡/门卡（Access Card）指可被系统单独赋权、停用与统计的电子凭证，优势在于可远程即时注销并记录刷卡时点，故管理以系统权限为准而非仅凭"手上有卡"；物理钥匙（Physical Key）用于开启个别房门、机房、配电或消防门，无法自动记录使用时点，须依靠登记簿人工留痕，其丢失往往意味着锁芯视同失密。万能卡/主钥匙（Master Key）可开启多门、多楼层或整栋，由 Property Manager 或 Duty Manager 严格控制，丢失或外泄即属须立即升级的安全事件；楼层卡/区域卡（Floor / Zone Card）授予单层或特定区域权限，用于清洁、维修、保安等人员，强调最小权限、按班领用、用完即还。

2.2 **尾随与权限注销。** 尾随（Tailgating）指在授权人员刷卡进入后未经独立授权紧随进入的行为，是进出控制最常见的漏洞，尾随者往往不持卡、不登记、无被访对象，故各站点应将其列为必须制止并上报的现场问题（见第 9 节）。权限注销（Access Revocation）指在系统中停用某卡或某人对某区域权限的操作，独立于物理回收：即使卡片未收回，只要系统已停用即无法再进入；反之卡已收回但系统未停用仍有被冒用风险，故注销必须即时、优先完成。

2.3 **缩略语。** PBSA=学生公寓；GR=长租公寓线；PMS=物业管理系统；APPs=Australian Privacy Principles；CCTV=闭路电视监控；WHS=Work Health and Safety。

## 3. 凭证类型与分级权限矩阵

3.1 **权限分级原则。** Safescan 对进出凭证实行"最小权限 + 按岗授权"原则，任何凭证只授予完成居住或岗位用途所必需的最低范围权限。权限分四级：一级为住户个人居住权限（房间+所属楼层+其分区公共区）；二级为访客限时权限（大堂+限定公共区+被访区域）；三级为员工岗位权限（运营区、机房与功能房）；四级为全域/万能权限（Property Manager 或 Duty Manager 的万能管理与应急权限）。权限越高，核验、登记与保管要求越严。

3.2 **凭证类型与授权对照表。**

| 类型 | 发放对象 | 权限范围 | 签发/保管要求 |
| --- | --- | --- | --- |
| 住户门卡（Room Card） | 在住住户 | 房间+所属楼层+其分区公共区 | 入住时发给，随入住 |
| 住户公共区卡（Common Area Card） | 在住住户（PBSA为主） | 健身房/公共厨房/自习区等 | 随入住配置，按房型与合同 |
| 访客卡（Visitor Card） | 已登记访客 | 大堂+限定公共区+被访区域 | 限时有效，前台登记，离场回收 |
| 员工卡（Staff Card） | 正式/兼职/外包员工 | 按岗位区分的运营区、机房、功能房 | 入职开卡，离职/换岗重新授权 |
| 楼层卡（Floor Card） | 清洁/维修/保安（班内） | 单层或限定层 | Duty Manager 班内签发，当班归还 |
| 万能卡/主钥匙（Master Key） | Property Manager / Duty Manager | 全楼或分区全域 | 签字领用，严禁带离站点 |
| 机房/应急钥匙（Utility Key） | Facilities Coordinator / 工程/值班 | 配电、水箱、机房、屋顶 | 限定岗位，登记保管 |
| 巡更/漫游卡（Patrol Card） | Security Officer | 全楼公共区+巡更点 | 班内领用，交接清点 |

3.3 **高权限凭证特殊控制与分区权限。** 万能卡/主钥匙、楼层卡与机房钥匙属高权限凭证，发放与回收必须由 Duty Manager 或以上岗位签字确认，并逐次登记使用人、时间、用途与归还状态；严禁长期外借、私自带离或交由未经培训人员使用，每次领用都应记录以便追溯。在"下住学生、上住长租"或同楼分层的楼宇中，进出控制必须按楼宇分区执行，学生区与长租区尽量设置独立分隔或门禁，住户卡只能进入其所属分区，员工的万能权限由站点按"分区授权"配置，并由 Property Manager 与该区值班经理共同确认留档。

## 4. 角色与责任矩阵

4.1 **前台/礼宾与住户服务专员。** Reception / Concierge 负责住户卡与访客卡的发放、登记与回收，受理钥匙/门卡服务请求，核验请求人身份与授权；其无权独立减免补卡费等费用，也无权在未核验身份的情况下交付凭证，涉金额、高权限卡或门禁异常时升级 Duty Manager。Resident Services Officer（学生线）负责学生入住的发卡、退租与换房的卡回收、公共区权限配置及与学校/代理沟通中的门禁安排，发卡时须一并核对在读证明、U18 监护要求与守则告知（联动 SC-PRD-008），并在开学期预编号、备卡、预留集中办理时段。

4.2 **值班与物业经理。** Duty Manager 负责高权限凭证的签发与回收、门禁异常处置与升级、开锁服务审批与费用判定，在网点范围内拥有进出控制的现场指挥权；Night Manager 在深夜独岗时段负责锁门后进出控制、无门卡住户处理、深夜开锁与应急高权限凭证使用，夜班用万能卡须记录并次晨移交 Duty Manager 复核，夜间开门尽量不单人近距离冲突（见 SC-SOP-003）。Property Manager 对进出控制合规与结果负最终责任，审批高权限凭证使用、决定补卡费/开锁费减免、确定门禁异常或安全事件的定性，并定期抽查发卡记录与审计日志。

4.3 **技术、安保与合规岗。** Facilities Coordinator 维护门禁、门锁、对讲与闸机等硬件，负责机房/应急钥匙保管与门禁故障报修复检（衔接 SC-SOP-009），锁具更换或门禁复位均须告知值班与物业经理。Security Officer 负责巡逻、尾随识别上报与门禁失效时的值守，准入与绩效纳入供应商管理；HSQE Manager 关注进出控制与应急疏散衔接，确保逃生门不被电锁锁死；Compliance Lead 关注监控/门禁数据隐私合规与各州禁止收费清单。

## 5. 前置条件与通用规则

5.1 **身份与资格核验。** 任何凭证在发放前，发放人必须核验请求人身份并确认其在系统中处于合法状态：住户须为在住且已签约、押金/订金到账符合要求（学生线另须在读与 U18 情况通过）；员工须入职登记并通过相应权限课程（见 SC-EMP-007、SC-TRN-002）；访客须有被访住户确认且完成登记。身份核验优先使用带照片的证件或系统已建档信息，避免单凭口述或"看起来像住户"就发卡。

5.2 **房态与权限配置正确。** 发卡前应在 PMS 确认目标房对为空置或住户名下、无未关闭的异常（欠租、待处理违规、未完成退租），并确认权限配置与合同/岗位一致。发卡后应核对卡号、权限范围与发放登记一致，任何不一致须当场纠正并记录，防止"卡发了、权限配错了"或"权限配了、卡没发"两类脱节。

5.3 **一人一卡、登记留痕、身份不明不交付。** 每张住户卡与每把钥匙对应唯一凭证记录，实行一人一卡、一房一钥匙，严禁多人共用、留作"备用"长期不还、或转借共享；员工因岗位需要可持多张不同权限卡，但须逐卡登记并由本人负责保管。所有凭证的发放、回收、补卡、注销都必须当场留痕，记录凭证编号、使用人、核验依据、时间、经办人与权限范围，无记录的发放视为未发放，责任由发放人承担。原则是"先核验、后发卡"，任何情况下都不得把凭证交给未核验身份的人员，也不得凭"住户说朋友来取"就交付；核对代取时须核对代取人身份与住户授权信息，无授权信息的代取请求不予受理。

## 6. 发放流程（编号步骤）

6.1 **步骤一：住户门卡发放。** ①核验住户身份与签约/在住状态；②在 PMS 确认房对与权限范围；③为新卡在门禁系统登记权限；④发放唯一卡并核对编号；⑤在发放登记表记录凭证号、房号、住户姓名、时间与经办人；⑥同步到入住清单（SC-SOP-007）。注意：发卡前务必确认押金/首期到账；发放后应请住户测试能否正常刷卡进入房间与楼宇。

6.2 **步骤二：访客卡发放。** ①登记访客姓名、证件、被访住户、到访时间并确认被访住户在住；②经被访住户确认；③发放限时访客卡并注明有效时段与允许进入范围；④告知访客禁止转借、须随身携带、离场时归还；⑤离场时收回并登记，超时未离场的升级 Duty Manager。注意：访客卡权限应严格为"限定公共区+被访区域"，不得赋予其住户房卡权限，访客不得在无人陪同情况下进入高权限区域。

6.3 **步骤三：员工卡发放。** ①确认员工已完成入职登记并通过岗位权限课程（见 SC-TRN-002）；②按最小权限原则为岗位配置权限；③在系统中开卡并记录卡号、岗位、授权人与生效时间；④向员工说明使用规范、保密义务与离职回收要求（见 SC-EMP-009）；⑤将开卡记录纳入员工档案与权限台账。注意：员工卡权限应随岗位变动及时调整，调岗后 3 个工作日内完成重新配置（内部标准）。

6.4 **步骤四：楼层卡/万能卡发放。** ①核验领用人岗位与领用必要性；②登记领用人、领取时间、用途与预计归还时间；③由 Duty Manager 或以上签字确认；④用毕当班归还并清点核销；⑤高权限凭证带离站点须经 Property Manager 批准并记录。注意：万能卡严禁单人长时间持有或私自带离；交接班须当面清点并在日志注明"在借、已归还、待归还"数量。

## 7. 补卡与丢失流程（内部收费）

7.1 **丢失立即报告与两步走。** 住户或员工发现卡/钥匙丢失或疑似被冒用，应立即向前台或值班经理报告，报告越早越能在最短时间停用权限，降低被捡拾后尾随或冒用进入的风险；凡涉及高权限凭证丢失，无论是否找回都必须第一时间升级 Duty Manager 与 Property Manager。收到丢失或失效报告后，发放人应先停用该卡权限（注销或挂失），再受理补卡，顺序不可颠倒；若只补卡而不停用原卡，则原卡与新卡同时有效，等于把门禁权限交给了外部不明人员。

7.2 **补卡流程（编号步骤）。** ①核实请求人身份，确认其为凭证合法持有人；②在 PMS 查询原卡状态并标记为丢失/失效；③停用原卡权限；④收取补卡费（见 7.3）并开具收据；⑤在门禁系统为新卡配置相同权限；⑥新卡发放并登记；⑦在交接与台账记录补卡原因、费用与原卡处置。注意：补卡后原卡权限即被覆盖，若日后找回原卡不得擅自重启，须交回前台确认后再处理。

7.3 **补卡费（内部标准）与例外。** 补卡费为 Safescan 内部服务政策，非法规要求：标准住户门卡/公共区卡补卡费为 A$25/张；员工卡或楼层卡补卡由公司承担内部工本，一般不对员工个人收费，但员工故意损坏或违规转借导致补卡的，可依员工政策追究。补卡费的收取、减免与退款均须留记录，前台无权独立减免，减免须由 Duty Manager 或以上审批；站点可为确有困难的住户提供一次补卡费减免（每租约/每学期限一次，内部标准）。凡属门禁系统故障、卡本身正常失效而非住户原因导致的换卡，费用由公司承担，不向住户收费。

## 8. 锁门/开锁服务与收费

8.1 **适用范围与流程（编号步骤）。** 开锁服务适用于住户忘带卡、卡失效、门锁故障、反锁、物品落锁或家中突发状况无法自行开门等场景，须在保障住户生命财产安全与防止冒名开锁之间取得平衡。流程为：①核验请求人身份与开锁请求权；②在紧急情况（房内小孩被困、疑似医疗/火情）下优先保障救助并立即呼叫 Duty Manager 与应急力量；③记录开锁时间、原因、经办人与所用方式；④开锁后请住户现场确认并记录；⑤将开锁记录纳入交接与台账。注意：为住户本人开锁前，应确认其确为该房对住户或经授权的合法占有人；对无法确认身份或存在可疑迹象的开门请求，一律不予开启并上报值班经理与保安。

8.2 **开锁服务费（内部标准）与应急区分。** 开锁服务费为 Safescan 内部服务政策，标准为 A$45/次，深夜（22:00–07:00）或节假日由站点统一口径执行。因门锁/门禁机械故障或系统失效导致的锁门服务费用由公司承担，不向住户收费；因住户自身原因（忘带卡、卡损坏、反锁）导致的服务，按开锁服务费执行，费用判定与减免由 Duty Manager 审批并留记录。开锁须区分"住户自行原因"与"公司设备故障"：凡因门锁损坏、门禁系统故障、消防困人、需紧急救助等情况，属应急或设备问题，应优先保障安全并免除或另行结算住户费用；若涉及火情、医疗或人身危险，应按 SC-SAF 相关应急文档先期处置，开锁由现场最高级别应急责任人协调，而非按常规开锁流程收费处理。

## 9. 使用规范：禁尾随、禁转借与门禁异常上报

9.1 **禁止尾随与转借。** 尾随是进出控制中最需防范的安全漏洞，所有持卡与无卡人员都应逐个经核验进入；凡发现有人试图尾随（紧随刷卡人员、趁门未关快速穿行、利用外送/搬运/清洁间隙混入），现场员工与保安应礼貌制止并提示其走正常登记通道。住户卡、员工卡、楼层卡与万能卡一律禁止转借、共享、出售或用于非授权用途，因为转借会使凭证脱离受控记录，导致"卡在谁手上无法追溯、权限是否被滥用无从判断"，是进出控制失灵的常见原因。

9.2 **禁止私自复制与门禁异常上报。** 任何员工不得私自复制、改装、克隆门禁卡或钥匙，不得绕过系统为他人"开权限"，不得把闲置卡长期留存；凭证的增补只能通过第 6、7 节的正规流程，由授权岗位在系统中配置，其余一概视为越权，发现转借或私自复制的按违规处理并评估是否需调整权限或停卡。当出现读卡器失灵、电动门锁异常、闸机误判、后台权限错乱、刷卡记录异常、对讲不通或访客卡超时未还等情况，现场人员应记录现象并即时上报 Duty Manager；区别"技术故障"与"疑似安全事件"：技术故障走维修（SC-SOP-009），若怀疑被入侵、被克隆、被恶意改动权限或涉越权访问，应按安全事件升级至 Property Manager、HSQE Manager 与 SC-SAF-008 相应处置，必要时报警。站点应保证主入口、车库层、垃圾房、公共洗衣房等易被利用区域的门禁与视线覆盖有效，门禁临时失效或夜间值守薄弱时加强人工值守并做记录（联动 SC-SAF-013）。

## 10. CCTV 联动与隐私合规

10.1 **运营联动与隐私边界。** 进出控制与 CCTV 协同构成楼宇安全的信息闭环：门禁刷卡时点、闸机通行与电梯记录可辅助还原事件时空，CCTV 画面可补足现场视觉证据，配合用于入侵、尾随、纠纷、物品遗失与违规事件处理；门禁/CCTV 日常运营与系统失效处置见 SC-SAF-013，监控点位、录像保存与调取的合规要求严格按 SC-REG-008 执行。门禁刷卡与到访记录涉及个人行踪元数据，CCTV 对可识别个人的录像属个人信息，均受《Privacy Act 1988 (Cth)》及 APPs 约束，故站点应做到：监控覆盖公共区域与安防点位，不得将摄像头对准房间内部、卫生间、更衣室等私密区域；在醒目位置设置监控提示标识；对监控与门禁数据访问限于有业务需要人员并留有访问日志；对住户信息调取、披露与保存遵循最小必要与告知原则。凡涉及监控系统新增点位、升级或人脸识别类功能的，须先做隐私影响评估（PIA）。

10.2 **数据调取与披露。** 为处理投诉、纠纷、调查或配合警方/监管而需调取门禁记录或 CCTV 录像的，须经 Duty Manager 或以上审批，并记下"谁、何时、为何查看"。除法定情形或住户本人授权外，不得向无关第三方披露住户进出记录；向警方、福利机构或学校等第三方披露的，须核实其身份与请求依据，遵循州法与机构协议，第一时间联系专业机构而非自行判断（见法规基线 B 节）。

## 11. 退租/离职卡回收与权限注销时限

11.1 **住户退租回收。** 住户退租（Move-out / Check-out）当天，前台应按 SC-SOP-008 收回所有钥匙与门卡，核对卡类型，并在系统中即时注销该住户的进出权限。权限注销须在回收后第一时间完成（内部标准：回收后 2 小时内完成系统注销），以防住户离开后仍持有效入房凭证；退租交还前，前台应检查是否有漏还的钥匙/门卡、信箱/车位/储物间是否已一并归还，并在系统标注房对为空置、待清洁/待检修。退租后原住户不得再持有可进入房间或楼宇的凭证，如住户以"反正要退租"为由想扣留门卡，站点应坚持回收并提醒如遗失按补卡/扣款流程处理，避免"人已退、卡还在外面"的漏管。

11.2 **员工与承包商离场回收。** 员工离职、转岗或不再需要某项权限时，应按 SC-EMP-009 在离职流程中回收工牌与全部门禁卡，并在其最后工作日前完成权限注销，防止离职人员仍可进入站点（内部标准：权限注销不得晚于员工离职当日 18:00）。外来承包商、供应商、保洁外包、临时工的门禁卡或登记权限，应按项目期限设置有效期，任务结束时权限自动到期或被回收，其准入与退出纳入供应商管理（见 SC-TRN 类）。

11.3 **台账完整性。** 站点应保存一份完整的"卡片/钥匙台账"，涵盖每张卡的编号、持有人、权限范围、发放/回收日期、变更记录与当前状态（在用/挂失/停用/已回收）。季度由 Property Manager 或授权人员对台账与实际卡片做一致性盘点，核对在卡、在借与已注销数量是否一致，确保权限配置与实际持有人对得上。

## 12. 异常与升级

12.1 **门禁大面积故障与入侵事件。** 若楼宇门禁、闸机或对讲大面积失效，现场人员应立即升级 Duty Manager，同时采取人工值守与临时管制：在入口设置登记、核验身份后放行，重点区域安排保安或值班人员盯守；故障期间应优先保障消防疏散通道畅通，修复后须复核权限配置未被系统恢复过程改变。发现有人尾随进入、无授权进入楼宇或出现入侵迹象时，按 SC-SAF-008 处置：保持镇定、确认其是否已登记、在不惊动对方的情况下记录其去向并通知值班经理与保安，避免当面质问或阻拦；若涉及人身威胁或持械，立即按 SC-SAF-008 的 Lockdown 与报警流程执行，员工的生命安全始终高于财产与记录。

12.2 **疑似卡被克隆或权限被改动。** 当出现刷卡记录异常（某卡在非持有人的时间/地点刷卡）、多个卡权限错乱或发现有人试图复制卡时，属疑似安全事件：应立即停用相关卡、上报 Property Manager 与 HSQE Manager，调取门禁与 CCTV 记录核查，评估是否需更换锁芯或重置权限，必要时报警。员工不得自行"查一下卡是不是坏了"就了结，须按安全事件处置。

12.3 **高权限凭证丢失或涉法律边界争议。** 万能卡、楼层卡、机房钥匙等高权限凭证丢失，属必须立即向 Duty Manager 与 Property Manager 上报的安全事件，除停用权限外还应评估是否需视同失密而更换相应锁芯/重置权限并留痕。当住户对补卡费、开锁费或凭证相关责任划分提出异议，或涉法定权利（进房权、通知义务、禁止收费清单）时，前台不得自行承诺或裁决，应升级到 Duty Manager，再按需升级 Property Manager 与 Compliance Lead；凡涉法律边界的，一律以州现行法及官方指引为准。

## 13. 红线（绝对不能做）

13.1 **不在未核验身份时发放凭证或开锁。** 严禁将钥匙/门卡（含万能卡、楼层卡）交给未经核验身份或授权的人员，严禁在无被访住户确认情况下放行访客、为不明身份者开锁，或对外来人员"先放进来再说"；任何一次未核验的放行，都可能成为尾随、入侵或纠纷的开端。严禁对尾随、强行进入、冒名领取、持伪造证件或拒不登记等行为视而不见、私自放行或给予"破例"，任何人不得因"怕麻烦""反正没出事"而对尾随睁一只眼闭一只眼。

13.2 **不转借、不复制、不滥用监控或影响疏散。** 严禁员工借用、共享、倒卖、复制、克隆门禁卡或钥匙，严禁把闲置卡长期留存或个人保管不归还；凭证的每一次流通都应可追溯，任何脱离受控记录的凭证流转都属于违规。严禁擅自改动摄像头指向房间、卫生间、更衣室等私密区域，严禁以与岗位无关的目的调取、下载、外泄门禁记录或 CCTV 录像或向无关第三方披露住户进出数据，违反属严重违规并可能触犯《Privacy Act 1988》及 APPs（见 SC-REG-008）。严禁将逃生门、消防通道的门禁配置为断电或火灾时无法开启、或在处置门禁故障时堵塞疏散通道，进出控制与消防疏散冲突时人员安全与疏散能力优先（见 SC-REG-009）。

13.3 **不擅自承诺费用或权利。** 严禁前台或任何员工未经授权向住户承诺减免补卡费/开锁费、承诺法定通知期限、续约/退款/转租结论等涉及金额与权利的事项；凡涉费用与法定边界，一律升级到有权岗位并按州现行法及官方指引执行。

## 14. 记录保存与执行监督

14.1 **必需记录与保存期限。** 本 SOP 各项操作应保留以下记录：发卡/发放登记表（凭证号、使用人、权限、时间、经办人）、访客登记与访客卡发放/回收记录、凭证领用归还台账（含高权限凭证签字）、补卡申请与补卡费收据、开锁服务记录、门禁异常与疑似安全事件记录、CCTV/门禁数据调取与访问日志、交接班"物理区"清点记录、以及权限注销与台账盘点记录。上述记录统一归档到 PMS/门禁后台与站点档案，发卡登记、访客记录与交接日志建议至少保存一个完整值班周期（不少于 30 天，内部标准）；涉及安全事件、门禁异常、数据调取与隐私争议的记录，应按事件档案长期保留并纳入审计，具体保留期限如与州法或《Privacy Act》要求冲突，以较严者为准。

14.2 **记录完整性与审计配合。** 记录必须真实、完整、可追溯，禁止事后补记、涂改或删除关键信息。Property Manager 每季度组织一次进出控制记录抽查，核对台账与实物、发卡与权限、回收与注销是否一致；内部审计与监管部门调取时，站点应完整提供相关记录，凡显示"人员、时间、权限、凭证"链条完整的记录，才可作为事件还原与责任认定的依据。

14.3 **培训与违规后果。** 所有涉及发卡、开锁、访客登记、门禁操作与监控调取的岗位，均须完成进出控制培训并通过考核后才能独立操作；新员工入职培训须含门禁与钥匙管理模块（见 SC-TRN-002），在岗员工每年复审一次。违反本 SOP 的人员，按其行为性质与后果分级处理：一般操作疏漏由直属主管纠正并记录；涉及发放凭证、开锁、数据调取等纪律性违规，按 Safescan 员工政策处理并视情节升级；构成隐私、反歧视或安全类违规的，按相应法规与合规文档评估外部责任（见 SC-REG-008）。因故意隐瞒、拖延上报导致安全事件扩大的，属严重违规并可能承担相应责任。
